# Варианты оформления и музыки для гео-канала (выбор владелицы)

Картинки `style_A..D.jpg` показывают четыре стиля на одних и тех же кадрах: цифра на видео, плашка места, карта и график.
Перерисовать их можно командой `python3 style_preview.py <папка с фонами>`.

| | Стиль | Шрифт | Цвета |
|---|---|---|---|
| A | Чистый белый, минимализм в духе National Geographic | Inter | белый, без акцентного цвета |
| B | Скандинавский: светлые карточки | Manrope | тёмно-синий, светлый беж, норвежский красный |
| C | Кино: элегантный, с засечками | Playfair Display + Inter | кремовый, золотые тонкие линии |
| D | Яркий инфографический, весёлый | Unbounded + Manrope | бирюзовый + коралловый |

Шрифты — Google Fonts (SIL OFL), можно использовать в коммерческих роликах.
