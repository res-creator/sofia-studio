# Задача: живой монтаж «Исландии» по всему фильму

Владелица канала посмотрела тест (отрывки u10–u19 и n01–n09, см. `media_list.py`, блок «ТЕСТ «ДИНАМИКА»») и одобрила подход. Теперь так нужно сделать весь фильм.
Главная претензия: «слишком долго один кадр стоит, пока идёт текст диктора, скучно». Она любит динамичные видео: «чаще менять, не задерживаться на одном кадре, видео интереснее фото, бери интересные видео отовсюду».

## Жёсткие правила
- **Озвучку не трогать.** Не вызывать ElevenLabs и Fish, не трогать `vo/`, `tts*.py`, `tags.py`, `script.py`, `align.py`. Тайминги склеек (ключи вида `a01`) не меняются, общая длительность тоже (21:26).
- **Править только свой файл** `rework/dyn_<ЧАСТЬ>.py`: `def apply(ns): ...`, который дополняет `ns['SHOTS']`. Пример ниже. Не редактировать `media_list.py`, `render.py`, `timeline.py`, `sources.py`, `../lib/*`. Не делать git commit и push.
- **Не трогать ключи других частей** и ключи, отданные под рисованные анимации: `a03 a04 f11 f12 j11 j14 j15 o17 o18` (ими занимается часть E).
- **Лицензии:**
  - Pixabay (видео и фото): ключ API берётся только из переменной окружения `PIXABAY_API_KEY`. Не печатать его и нигде не сохранять.
  - Wikimedia Commons и Flickr: только CC0, public domain, CC BY, CC BY-SA и «No restrictions». NC и ND нельзя.
  - Новостные кадры: только с явной свободной лицензией.
  - Автор и лицензия сохраняются автоматически через `sources.py` (функции `pv`, `pp`, `wk`, `fl`, `cv`).
- **Честность:**
  - Кадр, снятый не в Исландии или не во время события, не выдавать за него. Подпись места `loc=` ставить только на проверенные кадры.
  - Иллюстрации допустимы для общих действий (деньги, суд, корабль в шторм), но без подписи места.
  - Современные кадры не выдавать за архив, случайных людей не выдавать за участников событий.
- **Повторы:** один и тот же клип можно использовать повторно только с другим `ss` (другим моментом) и не в соседних минутах. Проверочный скрипт ниже.

## Что сделать с каждым планом своей части
1. **Ритм.**
   - Ни одна картинка не держится дольше ≈ 2,5 с. Исключение — анимированные карты и графики (`M(...)`): их можно держать до ≈ 6 с.
   - План длиннее ≈ 2,8 с разбивать на 2–4 коротких кадра через `S(part1, part2, ..., w=...)`. Части — это обычные `V(...)`, `P(...)`, `W(...)`, `FL(...)`, `CV(...)`, а `w=` задаёт долю длительности.
   - Короткие планы (меньше 2 с) не дробить.
2. **Видео важнее фото.**
   - Искать подходящие по смыслу фразы видео: на Pixabay (`pool.json`, `rework/pix_pool.json`; новые запросы через `rework/pix.py "запрос"`) и на Commons (`rework/research.py commons --video "запрос"`, скачивание через `rework/dl_slow.py`; upload.wikimedia.org часто отвечает 429, поэтому брать вариант `720p.vp9.webm` или `1080p.vp9.webm`).
   - Кадр должен иллюстрировать конкретные слова диктора: действие, людей, работу, место.
3. **Фото — с движением** (`motion=`, модуль `../lib/motion.py`):
   - `'parallax'` — пейзажи;
   - `'split_zoom'` — люди («два кадра из одного фото»);
   - `'tilt3d'`, `'push'`, `'rack'` — разное;
   - `'pan_fast'` — панорамы;
   - архив и вертикальные фото: `fit=True` + `motion='auto'`.
4. **Крупный текст диктора** (`kt=dict(lines=[...], hl=[...], pos='center'|'lower', size=..., at=[...])`):
   - Примерно одна фраза на 30–45 секунд: самые сильные цифры, цитаты, повороты.
   - Слова появляются под голос. Время слов в плане даёт `python3 rework/words.py <ключ>`, оно передаётся в `at=[...]` для каждого показанного слова.
   - `hl` — 1–2 главных слова, они будут бирюзовыми.
   - Не дублировать там, где уже есть `txt=` (цифра с подписью), карта или `loc=` на том же отрезке.
5. **Сохранять** удачные карты (`M(...)`), анимированные графики, настоящие архивные кадры и проверенные снимки Исландии. Их можно разбавлять, но не убирать.

## Синтаксис (функции из `media_list.py`, доступны в `ns`)
```python
# rework/dyn_A.py
def apply(ns):
    V, P, W, FL, CV, S, M = (ns[k] for k in ('V', 'P', 'W', 'FL', 'CV', 'S', 'M'))
    KB, KL, KR, KI, KO, KS = (ns[k] for k in ('KB', 'KL', 'KR', 'KI', 'KO', 'KS'))
    ns['SHOTS'].update({
      'b09': S(V(62005, 'каменная пустыня нагорья', 'Исландия', ss=4),
               V(123456, 'дорога через нагорье', 'Исландия', ss=2),
               P(2090429, 'лавовое поле', 'Исландия', motion='parallax')),
      'c11': S(..., kt=dict(lines=['вход в ад'], hl=['ад'], pos='lower', size=96, at=[2.1, 2.4])),
    })
```
- `V(id, что, где, ss=)` — видео Pixabay; id должен быть в `pool.json`, иначе сначала добавить его в пул.

  Новый Pixabay-клип, которого нет в `pool.json`, добавлять в `pool.json` по образцу (поля: url, user, page) из `rework/pix_pool.json`. Ещё вариант: собрать запись через `sources.pv` после того, как `pool.json` дополнен. Сохраняйте `pool.json` с `ensure_ascii=False, indent=0`. Перед записью перечитайте файл: его могут одновременно дописывать другие помощники. При чтении/записи используйте простую блокировку `fcntl.flock`.
- `P(id, ...)` — фото Pixabay (`photopool.json`).
- `W('Имя файла.jpg' или номер строки wiki_rows, что, где, kb, ...)` — фото Commons.
- `FL(flickr_id, ...)` — фото Flickr из `rework/flickr_db.json` (поиск: `python3 rework/flickr.py tag 6 "запрос"`).
- `CV(commons_name, 'local.webm', ...)` — видео Commons из `../data/commons_vid/`.
- `S(*части, **общие_ключи)` — быстрые смены. Общие ключи (`kt`, `loc`, `txt`, `tr`, `locator`) действуют на весь план.

## Проверка своей части (обязательно)
1. Скачать новые исходники: `python3 fetch_media.py`.
2. Отрендерить кусок со звуком: `python3 rework/test_clip.py <первый_ключ> <последний_ключ> rework/qc_<ЧАСТЬ>.mp4`. Длинную часть рендерить кусками по 2–3 минуты.
3. Сделать контакт-лист (ffmpeg `fps=1,tile`) и **посмотреть глазами** (Read PNG/JPG). Проверить:
   - соответствие кадра словам;
   - нет чёрных кадров, водяных знаков, логотипов, чужих титров;
   - текст читается;
   - нет случайных повторов.
4. Повторы по всему фильму:
   `python3 -c "from timeline import build; ..."` — собрать все (m, ss) из `seq` и обычных планов и убедиться, что пары не совпадают.
5. В отчёте:
   - список изменённых ключей (было → стало, коротко);
   - новые источники (автор, лицензия);
   - что не нашлось.
