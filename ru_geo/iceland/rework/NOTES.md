# Доработка видеоряда «Исландии»: что не нашлось, платные варианты, запрос автору

## Где искали
- **Wikimedia Commons**: поиск MediaSearch, около 140 запросов. Сведения об авторе, лицензии и дате взяты со страницы каждого файла (`commons_db.json`). Оттуда же видео: репортаж Kanal13 (CC BY 3.0), съёмка с дрона Swedrone (CC BY 3.0), видео Mladen Stojanovic (CC BY 3.0).
- **Flickr**: только фото с лицензиями CC BY, CC BY-SA, CC0 и Public Domain Mark. Дату и место проверяли на странице фото (`flickr_db.json`).
- **Pixabay**: около 70 запросов про людей и работу. Исландских сюжетов с людьми там почти нет, поэтому новых кадров с Pixabay не брали, кроме одного: на 14:31 переставлен уже использованный в ролике кадр «траулер тянет сеть, вид сверху» (иллюстрация).
- **Pexels**: недоступен из этой среды. API требует ключ, а сайт отвечает 403.
- **Mixkit**: кадров с исландскими рыбаками, насосами и эвакуацией нет, есть только общие городские сюжеты.
- **Архивы**: Национальный архив Нидерландов (через Commons): треска, 1934. Библиотека Корнелла (Howell, около 1900). Фотоархив Рейкьявика (Магнус Оулафссон, «нет известных ограничений»). USGS и NASA (public domain). Signal Corps (США, 1943).
