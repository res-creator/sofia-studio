# Подбор кадров для выпуска «Дубай» (≈ 26 мин)

Работаем по скиллу `.claude/skills/skvoz-strany/SKILL.md` (шаг 6) и правилам `ru_geo/docs/RULES.md`.
Сценарий: `ru_geo/dubai/SCRIPT.md`. Абзацы диктора: `ru_geo/dubai/vo_full/lines.json` — у каждого `id` (c00_xx — холодный старт и трейлер,
c01…c07 — главы), `text`, `hint` (что в кадре по замыслу сценариста), `est_dur` (оценка длительности, сек; озвучки ещё нет) и `n_shots` (сколько кадров).
Музыкальные паузы: `ru_geo/dubai/vo_full/interludes.json` — `after` (после какого абзаца), `sec`, `hint`. Для пауз — только самые красивые пролёты (дрон, таймлапс, закат).

## Результат
`ru_geo/dubai/shots/<часть>.json`:
```json
{"c01_01": [[123456, 3, 1.0, "что в кадре"], ["img", "ae/creek_1950.jpg", 1.0, "Крик в 1950-х (фото Commons)"]],
 "pause:c01_05": [[...], ...]}
```
Элемент видео: `[pixabay_id, ss, вес, "что в кадре"]`; фото: `["img", "ae/<имя>.jpg", вес, "что в кадре (фото Commons)"]`. Для пауз ключ `"pause:<after>"`.
Пиши только свой файл; авторов фото — в `ru_geo/dubai/shots/commons_credits_<часть>.json` (`{"ae/x.jpg": {"page","author","license"}}`). Git не трогать.

## Источники
- Pixabay API: `import sys; sys.path.insert(0,'ru_geo/lib'); import pixabay; pixabay.search('dubai marina', video=True, n=200)` (ключ только из env `PIXABAY_API_KEY`,
  не печатать). У hit: `tags`, `duration`, `videos.large.width` (3840 = 4K), `videos.medium.thumbnail`. Превью смотреть контакт-листами (PIL) через Read.
  Спорные клипы — скачать `videos.tiny.url` во временную папку и посмотреть 3–4 кадра.
- Архив и то, чего нет в видео (Крик 1950-х, ловцы жемчуга, шейх Рашид, первые нефтяные платформы, Кунху/рабочие — только общие фото без выдачи за конкретных людей):
  Wikimedia Commons (`lib/commons_find.py`: `search(q, n)`, `thumb_url(name, 1920)`; `lib/commons_html.py`: `info('File:…')` — лицензия/автор).
  Только CC0 / Public domain / CC BY / CC BY-SA, без NC/ND. Сохранять в `ru_geo/data/commons_img/ae/<короткое_имя>.jpg` (≥ 1600 px, горизонтальные).
  Фото — не больше половины кадров абзаца и не больше 2 подряд (кроме главы 1 про 1950-е: там архив может идти чаще).

## Правила (уроки прошлых выпусков)
- «Говорим — показываем»: каждый кадр показывает то, что звучит в эту секунду (Крик — Крик, абры — абры, Бурдж-Халифа — Бурдж-Халифа, опреснитель — опреснитель).
- **Только Дубай / ОАЭ там, где речь о Дубае.** Ловушки: Абу-Даби (мечеть шейха Зайда, Лувр Абу-Даби), Доха, Эр-Рияд, Кувейт, Бахрейн, Маскат — не выдавать за Дубай.
  Абу-Даби можно, только когда текст про Абу-Даби/ОАЭ. Нейтральные кадры (пустыня, кондиционер, вода из крана, самолёт в небе) — без подписи места.
- Нельзя: ИИ-генерации (теги «ai generated», «идеальные» лица/руки, ширина 3872 с длительностью ~5 с), 3D/CG, слайд-шоу, водяные знаки, логотипы брендов крупно,
  чужие титры, тёмные/мутные/вертикальные, статичные. Рабочих показываем с уважением, лиц крупно без нужды не берём; не выдаём случайных людей за героев (Кунху, Сантош).
- Абзац про события 2026 года (`<!-- 2026 -->`): только нейтральные кадры (пустой терминал, табло, небо, город) — без ударов, огня, военных.
- 4K приоритет, не меньше 1920. От `ss` до конца клипа ≥ (длительность кадра + 2) с.
- Внутри части клип — один раз. Перед концом сверь с другими готовыми файлами `shots/*.json` и убери совпадения.

Сколько абзацев закрыто, что не нашлось (замены), какие фото Commons взяты (лицензии), список клипов не в 4K.
