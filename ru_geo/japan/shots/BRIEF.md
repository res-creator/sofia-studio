# Подбор кадров для полного выпуска «Япония» (≈ 11,5 мин)

Озвучка готова: `ru_geo/japan/vo_full/lines.json` — 47 абзацев (id `c01_01`…`c10_04`), у каждого `text`, `dur` (сек) и `n_shots` (сколько кадров нужно, ≈ 3 с на кадр).
Сценарий с подсказками, что в кадре (строки `*(...)*`): `ru_geo/japan/SCRIPT.md`. Стиль: живой рассказ путешественника, современная Япония,
только **красочные, сочные, настоящие** видео.

## Что сделать
Для каждого абзаца своей части выбрать `n_shots` видеоклипов Pixabay (можно ±1), которые показывают **именно то, о чём говорят слова**
(Сибуя — перекрёсток Сибуя, рамен — рамен, олени Нары — олени и т. д.). Порядок кадров — в порядке слов в абзаце.
Записать результат в `ru_geo/japan/shots/<часть>.json` (ничего другого в репозитории не менять, git не трогать):
```json
{"c01_01": [[243075, 4, 1.0, "Токио с высоты"], [181114, 1, 1.0, "Сибуя сверху"]], ...}
```
Элемент: `[pixabay_id, ss (секунда начала внутри клипа), вес длительности (обычно 1.0), "что в кадре"]`.

## Где искать
- Готовый пул ≈ 4 900 клипов: `ru_geo/japan/pool/pool.json` (ключ `px<id>`, поля tags, dur, w, likes, thumb, color). Превью: поле `thumb` (jpg).
- Новый поиск Pixabay: `import sys; sys.path.insert(0,'ru_geo/lib'); import pixabay; pixabay.search('ramen', video=True, n=80)`.
  Ключ берётся из переменной окружения `PIXABAY_API_KEY` — никогда не печатать его и нигде не сохранять. У каждого hit есть `videos.medium.thumbnail`, `tags`, `duration`, `videos.large.width` (3840 = 4K).
- Смотреть кадры только глазами: собрать контакт-лист из превью (PIL, подпись id на каждой плитке), открыть картинку через Read. Для спорных клипов можно скачать
  клип (`videos.tiny.url`) в свою временную папку и посмотреть 3–4 кадра (ffmpeg). Временные файлы — в /tmp/<часть>/, не в репозиторий.

## Правила
- Только настоящие съёмки Японии (или нейтральные кадры без места, если иллюстрируют общее действие: кофе, телефон, лапша крупно — без подписи места).
  Не выдавать другие страны за Японию: Китай, Корея, Тайвань, «азиатские» стоки — нельзя, если по кадру видно другую страну.
- **Нельзя:** нейросетевые генерации (теги «ai generated», неестественные лица/руки, «слишком идеальная» картинка), 3D/CG, аниме, мультфильмы,
  водяные знаки, логотипы, чужие титры, слайд-шоу из фото, тёмные/мутные/блёклые кадры, вертикальные видео.
- Предпочтение: ширина 3840 (4K), потом 2560/1920. Не меньше 1920.
- Ритм живой: в кадре должно что-то двигаться (люди, поезд, вода, дрон, таймлапс).
- `ss` выбирать так, чтобы от `ss` до конца клипа было ≥ 4 с; лучший момент клипа.
- Внутри своей части один клип — один раз. Не брать клипы вступления: 53789 4431 177314 241395 243075 248449 44621 41957 147893 181114 167404
  205346 202740 173522 202982 110790 208581 218735 218734 44622 40602 81032 53375 184370 (кроме случаев, когда другого кадра нет — тогда другой `ss` и пометка «повтор»).
- Если подходящего кадра нет (например, японский туалет с пультом, Кумамон) — взять ближайший честный вариант (общий план улицы/интерьера по смыслу)
  и в описании пометить «замена: …». Не выдумывать.
