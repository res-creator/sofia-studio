## 2. Проблемы по важности

Ещё есть **11:13.3 (#204, id 42806)**: вьетнамки на мраморе, тоже не Япония. Слова здесь: «снимайте обувь… туалетные тапочки». → Заменить на Pixabay «genkan» / «japanese slippers» / «shoes off entrance japan» / «ryokan entrance».
