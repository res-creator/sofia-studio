# v5: внесено по кругу 4 (viewer + judge)
- Старт с вопроса про дверь; «Ты придуман. Но через всё это прошли настоящие люди»; «закон написан за 27 лет до твоего рождения».
- Натурализация («по натурализации»), письмо в среду убрано (о программе узнают от знакомых и из газеты), причина отказов («закон») убрана, отказы 10-20 из ста (источники: 10-15 для китайцев, ~18 для всех прибывших), женщина «двадцать месяцев, 1939», «около двухсот стихотворений».
- Подписка перенесена в конец главы 1906 с мягкой шуткой про «двести вопросов»; ложное обещание «следующая история» убрано.
- Ответ про дверь прозвучал: «Ваш отец тоже сказал: на юг». «Брат» остался другом, шутка «счёт ничейный». «А на острове тебя ждёт барак».
- Финал: факты (станция, Вайс, 2009) идут перед выбором; последние абзацы только про выбор героя; цена молчания добавлена; строка со стены «вольный перевод».
- Confusion Program убрано из речи; P5 на слух проще; мотив программы: «Власти США опасались... так объясняют историки».
# ПРОВЕРИТЬ: номер строки со стены (AIISF Poetry Finder); «Инспекторы работают по закону, который писали не они» (оценочно, без источника); «Закон написан за 27 лет до рождения» (1882+27=1909, вымышленный герой родился 1909).
