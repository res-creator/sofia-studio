# План работы до 2 декабря 2026 (нон-стоп)

Цель владелицы: к 2 декабря иметь как можно больше готовых роликов «Мысленного эксперимента» (озвучка fish-клон Todd, ElevenLabs не трогаем до 5 декабря) и постов для Пикабу.

## Конвейер на ролик
1. Тема из QUEUE.md. Автор пишет SCRIPT.md, RESEARCH.md, photos.json по PAPER_FORMAT.md.
2. Максимум 2 круга критиков (зритель, судья, фактчекер). Критиков запускает основная сессия.
3. make_paper.sh: озвучка, фото, раскадровка, рендер, сведение (очередь `scratchpad/chain2.sh`, статус в `chain_status.log`).
4. Проверка по контрольным кадрам, фрагмент и готовый MP4 владелице (MP4 в git без LFS, сжатый).
5. upload_kit.txt (название, описание, теги в нижнем регистре, закреплённый комментарий) и PIKABU_POST.md (по ru_geo/HANDOFF_MYSL.md).

## Правила крючка (требование владелицы)
- Первые 30-60 секунд: открытая петля, зритель должен хотеть узнать, чем кончится. Без оговорок и лекций в начале.
- То же для постов Пикабу: интрига, повод комментировать, продолжение «по ссылке».

## Очередь
1. супермаркет, 2. Вселенная, 3. отдалённое место, 4. размер стран, 5. 7 мест, затем высота построек, почему трудно стать папой, как создать страну, значение названий стран; отложены: мегацунами, Титаник, Кракатау, остров.

## Железные правила
- Не писать ключи в код. LFS исчерпан: новые видео сжимать и коммитить обычным git.
- Диск: после рендера удалять кадры.
- Ответы владелице по-русски, просто, без длинных тире, честно о том, что не готово.
