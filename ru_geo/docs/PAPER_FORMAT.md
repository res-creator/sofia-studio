# Формат сценария «бумажного» ролика (для авторов и для сборщика)

Папка ролика: `ru_geo/<slug>/` (slug: латиница, нижний регистр). Файлы:
- `RESEARCH.md`: источники (URL) и таблица фактов: «утверждение | источник | уверенность». Каждая цифра и дата со ссылкой.
- `SCRIPT.md`: текст озвучки + разметка кадров (ниже).
- `photos.json`: какие фото нужны (ключи, запросы для поиска на Wikimedia Commons, подпись на экране).
- `review/`: отзывы критиков (по кругам).

## SCRIPT.md
```
# Название ролика

## ХОЛОДНЫЙ СТАРТ
>> {"card":{"photo":"key"}}              (необязательно: фон титульной карточки главы)

Абзац озвучки: 1-4 предложения, 20-60 слов, 8-16 секунд речи.
>> {"shots":["key1","key2"],"hero":{"emo":"worry","side":"R"},"tags":[["≈ 50 000",0.1],["жителей",0.4]]}

## СЛЕДУЮЩАЯ ГЛАВА
...
```
Правила:
- Главы: 5-8 штук, названия ЗАГЛАВНЫМИ, короткие. Первая глава всегда «ХОЛОДНЫЙ СТАРТ» (крючок за 15 секунд).
- После КАЖДОГО абзаца ровно одна строка разметки `>> {json}`.
- `shots`: 1-4 ключа фото из photos.json; абзац делится между кадрами поровну. Один кадр держится 3-6 секунд, не больше 8.
- `hero` (необязательно): мультяшный герой-наклейка поверх фото (реакция, не персонаж истории). `emo`: flat, sad, surprised, worry, grin, smug. `side`: L или R. Ставь героя не чаще, чем в каждом третьем абзаце.
- `tags`: до 3 жёлтых бирок на абзац: короткий факт (число, дата, место), до 28 знаков. Второе число: когда появляется бирка, доля длительности абзаца от 0 до 0,9.
- Карточка с цифрами вместо фото: `>> {"card":{"items":[["1 из 7","шансы мужчины в 3 классе"],["20","шлюпок"]],"bg":"key"}}` (1-3 карточки, bg необязателен).
- Теги озвучки в тексте: `[pause]` даёт паузу.
- Объём: 1100-1500 слов (8-10 минут). Русский, простой, без длинных тире «—» (используй двоеточие, запятую, точку), без штампов «не X, а Y».
- Ничего не выдумывай. Цифры только из RESEARCH.md. Спорное подавай как спорное («по оценкам», «по свидетельствам»).

## photos.json
```
{"key": {"q": ["запрос 1 по-английски", "запрос 2"], "cap": "подпись на экране", "need": "что на кадре"}}
```
- 14-24 ключа на ролик (каждый можно использовать 1-2 раза).
- Только то, что реально есть в свободных источниках (Wikimedia Commons: общественное достояние, CC0, CC BY, CC BY-SA). Названия мест, кораблей, людей, событий: английские запросы работают лучше.
- `cap` честный: если фото позднее или иллюстрация, так и пиши («фото 2019 года», «гравюра XIX века»).
