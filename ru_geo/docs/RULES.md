# Правила канала «Сквозь страны» (действуют для всех выпусков)

Основа — инструкция `PROCESS_GUIDE.md` (процесс канала-партнёра, передан владелицей 09.11.2026).
Из неё берём процесс, тон, правила качества и монтажа. **Не берём** их оформление и названия: имя «Пристегнитесь!», фразы «пристегнитесь / пристёгивайся»,
их плашки, шрифты, цвета, заголовки фильмов. У нас свой дизайн: Cormorant Garamond + Inter, бирюзовый акцент, красная печать-ханко страны, полосы кино.
Если владелица говорит иначе — её слово главнее; новые правила сразу дописывать сюда.

## Уже применяем
- Только настоящие кадры, каждая фраза показывает свой предмет («говорим — показываем»), проверка листами кадров перед рендером.
- Озвучка один раз по готовому тексту; переозвучка только фраз с реальной ошибкой; проверка Whisper.
- Команда помощников: исследователь, сценарист, критики, фактчекер, монтаж; критики проверяют черновик по пунктам.
- Финал 4K: HEVC 10 бит ≈ 20 Мбит/с, тег hvc1, звук AAC 320k, −14 LUFS; субтитры .srt отдельным файлом (не вшивать).
- Описание: крючок, главы с таймкодами, строка «Озвучка сделана с помощью ИИ, факты проверены по источникам», авторы по лицензиям, хэштеги;
  при загрузке отметить «изменённый/синтетический контент», если YouTube спрашивает. Закреплённый комментарий-вопрос с вариантами.

## Со следующего выпуска
- Сначала короткий тест 2 минуты нового стиля → «да» владелицы → весь фильм.
- Сценарий идёт в озвучку, только когда оба критика («Зритель с телефона» и «Честный судья») ставят 10/10 по каждому пункту; таблицу оценок по кругам сохранять.
- Длина 25–34 минуты, весь фильм — один большой крючок; контраст: красота и трудная сторона (с уважением и цифрами из ООН / ВБ / официальной статистики);
  истории людей; ~30 с философской паузы, если уместно; одна остроумная просьба подписаться на 20–30 % фильма.
- Шуток мало, но точных; теги смеха редко.
- Ритм: вступление ~1 план/с, дальше 2–4 с, каждые 1–3 мин 10–40 с только музыки и красивых пролётов.
- Название страны за движущимся объектом (маска rembg), название места в пейзаже с трекингом, «окно» с закруглёнными углами — в нашем дизайне.
- Текст на экране редко: рукописные подписи ≤ 5 на фильм, облачка животным ≤ 2, никаких «чеков», ничего короче 1,5–2 с, в надписях короткое тире «-».
- Обложка: одно яркое изображение, 2–4 крупных слова, читается в 160–320 px, герой перед названием; 2–3 варианта листом владелице.
- После загрузки: закреплённый комментарий, шортсы из лучших моментов, отрывок на Пикабу/Дзен.
- Ответы на комментарии: 1–3 коротких простых предложения, без смайликов и длинных тире, добро даже на грубость.
