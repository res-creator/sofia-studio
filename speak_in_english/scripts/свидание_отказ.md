# «Как отказать в свидании» — сценарий v1 (по Skill v3)

**Открывашка (новый тип — стоп-кадр с подписью):** кафе. Незнакомец Брэд с розой в зубах подсаживается за столик героини. Стоп-кадр, подпись «ВИЖУ ЕГО ПЕРВЫЙ РАЗ». За соседним столиком девушка Джессика читает книгу и поглядывает на часы (засев для финала).
**Конфликт:** героиня хочет вежливо отказать. Брэд любой отказ понимает как знак надежды.
**Архитектура:** непрерывная эскалация за одним столиком. Каждый отказ добавляет романтики: сердечки → салфетка с её именем → скрипач → официант с кольцом.
**Детали для C2:** Джессика за соседним столиком, официант, скрипач.
