# «Не лезь не в своё дело» — сценарий v1 (по Skill v3)

**Открывашка (новый тип — «глаза над перегородкой»):** офис. Героиня переписывается в телефоне. Над перегородкой медленно поднимается голова коллеги Глории с огромными глазами. Подпись «ОНА ВСЕГДА РЯДОМ». На подоконнике за окном сидит голубь (засев).
**Конфликт:** героиня хочет личного пространства. Глория считает чужую жизнь своим сериалом.
**Архитектура:** непрерывная эскалация: заглядывает в телефон → крутится на стуле → зеркальце → звонит маме героини → отъезжает к своему столу… и бинокль.
**Деталь для C2:** голубь на подоконнике (хук).
