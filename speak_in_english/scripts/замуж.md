# «Почему ты ещё не замужем?» — сценарий v1 (по Skill v3)

**Связь с каналом:** возвращается тётя Пэм из «Ужасного подарка» (та же квартира, на героине её вязаный свитер). Это узнаваемо для зрителей, но сюжет новый. Сюжет не копирует внешний референс «Когда замуж?»: нет кота-жениха, другой финал.

**Открывашка (новый тип — допрос):** семейный ужин. Над столом лампа-«прожектор» светит на героиню, как на допросе. Тётя Пэм кладёт перед ней папку «CANDIDATES». Подпись «ДОПРОС НАЧИНАЕТСЯ».
**Конфликт:** героиня хочет спокойно поужинать. Пэм хочет её выдать замуж и готовится к этому как к спецоперации.
**Архитектура:** непрерывная эскалация за одним столом: папка кандидатов → календарь → жених Джеральд из кухни → бронь церкви → коробочка с кольцом.
**Детали для C2:** вязание Пэм (её «фишка» из прошлой серии), спицы на столе с первого кадра.
