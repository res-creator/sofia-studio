# «Соседка не моет посуду» — сценарий v1 (по Skill v3)

**Замена темы «Сосед делает ремонт»:** ремонт — та же жалоба на шум, что и хит «Соседи», поэтому другая бытовая война с соседкой по квартире.
**Открывашка (новый тип — «шкаф пуст»):** кухня. Героиня открывает шкаф: пусто. Камера отъезжает — в раковине башня посуды до потолка. Подпись «ЧИСТЫХ ТАРЕЛОК: 0». На полке одна чистая кружка с наклейкой MINE (засев).
**Архитектура:** непрерывная эскалация у раковины: коробка пиццы → стикер TOMORROW → сериал → график дежурств → бумажные тарелки.
**Деталь для C2:** кружка героини с наклейкой MINE.
