# «Мне не нравится твой парень» — сценарий v1 (по Skill v3)

**Открывашка (новый тип — «кража крупным планом»):** ресторан. Крупно рука Кайла медленно задвигает вилку в рукав. Подпись «ЭТО ПАРЕНЬ МОЕЙ ПОДРУГИ». Камера отъезжает: за столиком подруга Мия, влюблённо смотрит на Кайла, и героиня.
**Конфликт:** героиня пытается открыть подруге глаза. Мия всё оправдывает. Кайл за спиной Мии ворует всё больше.
**Архитектура:** непрерывная эскалация: вилки → пальто с подкладкой из приборов → «подарок» Мии (солонка ресторана) → свеча → ложка выпадает из рукава → стул.
**Деталь для C2:** слова Мии из A2 «он коллекционер».
**Отличие от «Не трогай мои вещи»:** там коллега одалживает вещи героини, здесь парень ворует у ресторана, а героиня спорит с подругой. Стул в финале — по ТЗ владельца.
