# «Ты поправилась?» — сценарий v1 (по Skill v3)

**Открывашка (новый тип — «улика в сумке»):** булочная. Героиня покупает торт. Сзади подкрадывается знакомая Линда, и из её огромной сумки торчит сантиметровая лента. Подпись «ОНА ПРИШЛА НЕ ЗА ХЛЕБОМ».
**Конфликт:** героиня хочет закрыть тему. Линда «заботится» и с каждым уровнем достаёт из сумки новый инструмент.
**Архитектура:** непрерывная эскалация у витрины. Сантиметр → напольные весы → полотенце-ширма → лупа → «объятие» с тайным замером.
**Деталь для C2:** весы из A2 остаются на полу до финала.
**Этика:** смеёмся над бестактной Линдой. Внешность героини не обсуждается, цифр нет.
