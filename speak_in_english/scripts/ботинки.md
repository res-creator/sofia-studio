# «Два левых ботинка» — сценарий v1 (по Skill v3)

**Открывашка (новый тип — открытие коробки):** крупно коробка с обувью, крышка отлетает. Внутри два ботинка… оба носком влево. Пауза. Подпись «ЧТО-ТО НЕ ТАК?». Камера отъезжает: героиня у кассы обувного магазина, продавец Найджел с безмятежной улыбкой.
**Конфликт:** героиня хочет нормальную пару или деньги назад. Найджел хочет закрыть вопрос, не признавая брак.
**Архитектура:** непрерывная эскалация у одной кассы. Решения Найджела всё нелепее, «левая» тема растёт.
**Детали для C2:** коробка с двумя левыми ботинками (хук), ваучер «LEFT SHOES ONLY» (C1).
