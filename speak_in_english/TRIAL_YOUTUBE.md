# THE TRIAL — первый длинный YouTube-выпуск (16:9)

Сценарий: `speak_long_ep1/SCRIPT.md` (версия 3). Реплики, карточки и монтажная последовательность для движка: `engine/episodes_v2.py` → `EP["trial"]`.

## Горизонтальный формат в движке

Формат выбирается **в конфиге серии**: `format="landscape"` → 1920×1080, 30 fps. Без этого поля серия, как и раньше, вертикальная 1080×1920.

| Файл | Что добавлено |
|---|---|
| `ui_v2.js` | Раскладка для широкого кадра: полоска A1–C2 сверху по центру (масштаб 0.7); карточка урока в боковой панели слева или справа (`UI.setCardSide`); пузыри под полоской и над субтитрами; субтитры диктора внизу; заставка уровня; водяной знак внизу справа. Поддержка `sc.done` (полоска уровней между уровнями) и `cd.chip` (заголовок карточки вне уровней, например «УЛИКА А»). |
| `ep_kit.js` | Размер кадра по формату; штамп и «…» по центру; горизонтальная концовка `outroLand` (персонажи и вопрос слева, шпаргалка и кнопки справа); части C2 не накладываются друг на друга. |
| `engine_v2.js` | Помощник композиции `camassist` не включается для 16:9: каждый план кадрируется вручную, режим `hard_cut`. |
| `qa_frames.js`, `prev_v2.py` | Проверка и превью понимают 16:9 (у YouTube из «опасных зон» только полоса плеера внизу). |
| `timeline_long.py` | Монтажный лист длинной серии из данных (`seq`): сцены-уровни и сюжетные сцены между ними. Пока голосов нет, длительность каждой реплики оценивается по тексту; после озвучки запуск того же скрипта подставит реальные тайминги. |
| `render_silent.sh` | Немой аниматик для проверки (`ANIMATIC=1` пишет в кадре тайм-код, сцену и план). |
| `trial.js` | Рендер выпуска: зал суда, персонажи, флешбэки на экране зала, вставки улик, раскадровка. |

**Обратная совместимость проверена:** вертикальная серия WRONG CHAT отрендерена до и после изменений с одинаковым зерном плёнки, кадры совпали побайтно (6 кадров, включая концовку).

## Как собрать

```bash
cd speak_in_english/engine
python3 timeline_long.py trial                      # монтажный лист (оценочные тайминги до озвучки)
python3 prev_v2.py trial "0;S['c2_her']['t']+3" sheet.png   # превью кадров
node qa_frames.js trial --step=0.5 --sheet          # проверка композиции
bash render_silent.sh trial out/trial_animatic.mp4  # немой аниматик (~10 мин на 4 ядрах)
```

## Зал суда и планы

Один большой зал «COURT 2»:
- кафедра судьи с гербом и часами;
- скамья подсудимой (DOCK);
- место свидетеля;
- стол истца;
- стол улик (колонка в пакете EXHIBIT A, коробки пиццы, сдутый фламинго, огнетушитель);
- экран для улик на стене;
- галерея со зрителями, пристав и дверь EXIT;
- высокие окна.

Отдельная декорация — ночной коридор у двери 13 для финала.

Планы, все неподвижные, со склейками по смыслу:
- общий (`WIDE`, `WIDE_L`, `WIDE_R`);
- одиночные: героиня, судья, Rocky, свидетели, Nana;
- реакции (`*_R`);
- карточные (`CARD_*`: лицо на одной стороне, карточка на другой);
- галерея, дверь, стол улик, экран (`SCREEN`);
- вставки на тёмном фоне: счёт, блокнот судьи, журнал колонки, волна записи, совпадение свиста MATCH, монеты, итоговый счёт.

Флешбэки (квартира Rocky из «Соседей», героиня в пижаме) играют в вертикальном окне на экране зала; пузыри указывают на героев внутри экрана.

Персонажи остались прежними; добавлены только аксессуары: парик и молоток судьи, слуховой аппарат и судок Наны, пиджаки Rocky и героини, фартук Kai.
