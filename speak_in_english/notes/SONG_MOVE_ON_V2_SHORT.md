# «Move on» — v2, короткая (~1:30), после критика

## Оценка критика (старая версия): 6/10
- Припев слишком длинный (8 строк); строка «I'm through» выпадала из ритма.
- Ошибки в английском:
  - «I'm breaking up» без продолжения значит «связь пропадает». Теперь «We're breaking up».
  - «I'm through» само по себе значит «я закончила дело». Теперь «I'm over you».
  - «Move on = не зови назад» — неверный перевод.
- Во втором куплете русская часть не совпадала с английской: clean up ≠ «разбираю полки», call up ≠ «зовут гулять» и т.д. Исправлено.
- Строки разной длины. Выровнено: куплет 5–6 + 7–8 слогов, припев 4–5 + 4–6.
- Шутка про «11 лет школы» гасила финал. Убрана, вместо неё «Я больше не плачу. I'm over you».
- Хук для тренда: **«I'm moving on — и не смотрю назад»**.
