# Формат «Рифма-запоминалка» (по референсам владелицы) — разбор, текст, запрос для Suno (исправлено)

## Как устроены референсы (прочитано по кадрам)
Текст идёт вперемешку: русский вопрос -> огромное английское слово, потом фраза-рифма.
1. Хук: ученик жалуется «Блин, английский такой сложный». Учитель: "Nah. It's easy." — «Правда?» — "Ask me anything."
2. Шесть-семь слов одного звука: «Как будет кошка?» -> C-AT; «Шляпа?» -> H-AT; «Коврик?» -> M-AT; «Крыса?» -> R-AT; «Летучая мышь?» -> B-AT; «Толстая?» -> F-AT; «Сидела?» -> S-AT. Английское слово на весь экран, общие буквы (AT) выделены жёлтым.
3. «Ладно... а как сказать:» — русская фраза строится по словам как караоке (Толстая кошка в шляпе сидела на коврике с крысой и летучей мышью?).
4. Та же фраза по-английски по словам с русской транскрипцией под ней («зэ фэт кэт ин э хэт»), буквы AT подсвечены.
5. Шутка в конце: "A little." — «Немножко.» — плашка ENGLISH IS EASY (немножко).
Монтаж: склейка каждые 1,2–1,3 секунды. Музыка непрерывная, речь в такт (темп около 108).

## Наша версия (около 65 секунд: вступление, два раунда по шесть слов, финал)
Вступление: Алина (по-русски) «Блин, английский такой сложный.» — Учитель "Nah. It's easy." — «Правда?» — "Ask me anything."
Раунд 1, звук -ight («айт»): Яркий -> bright; Свет -> light; Полёт -> flight; Рыцарь -> knight; Испуг -> fright; Ночь -> night.
 Русская фраза: Яркий свет в полёте напугал рыцаря прошлой ночью.
 Английская: A bright light in flight gave a knight a fright last night. («э брайт лайт ин флайт гэйв э найт э фрайт ласт найт»)
Раунд 2, звук -ake («эйк»): Змея -> snake; Печь -> bake; Торт -> cake; Делать -> make; Брать -> take; Озеро -> lake.
 Русская фраза: Змея может испечь торт, сделать его и отнести к озеру.
 Английская: A snake can bake a cake, make it and take it to the lake. («э снэйк кэн бэйк э кэйк, мэйк ит энд тэйк ит ту зэ лэйк»)
Финал: "See? Easy." — «Ну… почти.» — "A little." — плашка ENGLISH IS EASY (почти).
