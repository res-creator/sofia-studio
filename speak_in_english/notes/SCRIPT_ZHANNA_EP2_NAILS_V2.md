# «Тётя Жанна с Брайтона» — серия 2: «Жанна в салоне ногтей» (v2)

## Формат
- **Место:** маленький салон NAILS на Брайтоне. Розовые стены, лампа, бутылочки лака.
- **Мастер — Брук:** американка лет 25, жуёт жвачку, вежливая, говорит только по-английски. Её реплики идут с переводом.
- **Жанна:** говорит на рунглише, русифицирует глаголы (букаю, чекаю, тэгаю, коллбэкну), часто вставляет «ю ноу?».
- **Экран:** английские слова в субтитрах жёлтые, над ними плашка с переводом.
- **Длина:** около 55 с.

## Финал: «Переводим Жанну»
- APPOINTMENT — запись
- FRENCH TIP — френч
- GLOSSY / MATTE — глянцевый / матовый
- YOU'RE ALL SET — всё готово
- WOULD YOU LIKE TO ADD A TIP? — хотите оставить чаевые?
- TIP — 1) чаевые 2) совет 3) кончик
- YOU'RE WELCOME — пожалуйста (в ответ на «спасибо»)

**Вопрос в комментарии:** «Жанна права? Сколько вы оставляете мастеру: 0%, 10% или 20%? Пишите цифру».

## Голоса
- **Жанна:** голос из серии 1.
- **Брук:** молодой женский голос с хорошим английским.
