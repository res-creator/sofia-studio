# boring.mp4 — «I'm boring»: так говорят только русские

Пилот новой короткой рубрики **«Так говорят только русские»** — одна типичная ошибка за ~24 секунды (тест: короткие ролики против старого 2-минутного формата A1–C2).
Кадр 0 — уже живая сцена: кафе, героиня демонстративно зевает и вздыхает «I'm so boring...», сверху плашка-титул «ТАК ГОВОРЯТ / ТОЛЬКО РУССКИЕ / «I AM BORING»» (первые ~2.5 с). Пауза с тиканьем часов (музыка молчит) — и парень искренне кивает: «Yeah. You kind of are.» Встаёт, накидывает пальто и уходит; его чашка качается, по столу катится перекати-поле, звенит колокольчик двери, у героини шок.
Диктор + карточка: ✗ «I'm boring» = «я зануда» / ✓ «I'm bored» = «мне скучно», розовая подсказка «I'm bored.» Затем: «BORING» на часах, которые не идут, и «BORED» на зевающей героине. Финал: «КАКУЮ ОШИБКУ РАЗОБРАТЬ СЛЕДУЮЩЕЙ?», «СОХРАНИ», курсор нажимает «ПОДПИСАТЬСЯ».

## Языковые заметки
- boring — «скучный» (о том, кто/что нагоняет скуку): *I'm boring* = «я зануда».
- bored — «скучающий» (о том, кому скучно): *I'm bored* = «мне скучно».
- То же правило: interesting / interested, tiring / tired, confusing / confused.
