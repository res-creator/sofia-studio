# pingpong.mp4 — Игра «Ответь за 3 секунды» (выпуск 1)

Интерактивный формат: пушка-мячеметалка «стреляет» английской фразой, у зрителя реальные 3 секунды (мяч превращается в таймер), потом естественный ответ с переводом. 3 вопроса, финал: пушка пытается сесть на маленький стул. Один голос, без уровней A1–C2.

## Подпись (вставить целиком)
Пушка стреляет английской фразой, у тебя 3 секунды, чтобы ответить вслух 🎾⏱️
1. Thanks so much! → No problem!
2. What's up? → Not much. You?
3. Do you mind if I sit here? → Not at all! (это значит «нет, не против, садитесь»)
