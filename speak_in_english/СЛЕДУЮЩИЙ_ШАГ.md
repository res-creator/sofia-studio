# Серия «Забыла имя» (slug `names`) — что осталось

Готово и закоммичено: сценарий (`episodes_v2.py` → `EP["names"]`), ветка монтажа (`timeline_v2.py`), музыка-вальс (`audio_v2.py`), рендер `engine/names.js` (свадьба, обложка-бейдж «HELLO my name is ???», шпаргалка с кнопками СОХРАНИ/ОТПРАВЬ).
Раскладка проверена превью-кадрами на временных заглушках диктора. Заглушки в git не попадали.

## Что сделать в новой сессии (из папки `speak_in_english/engine`)
1. Проверить аккаунт ElevenLabs: `curl -sS https://api.elevenlabs.io/v1/user/subscription` — нужно минимум ~600 свободных символов (`character_limit - character_count`). Ключ в файлы не писать (подставляет прокси).
2. `python3 setup`-шаги из `ГАЙД`: если контейнер новый — `bash setup.sh` (модели Kokoro/Whisper не в git).
3. Диктор: `python3 eleven_nar.py names` → `python3 split_nar.py names` → `python3 asr_v2.py names ru` (Whisper-small обрывает фразы с английскими вставками, это норма; смотреть длины кусков).
4. Английские голоса: `python3 tts_v2.py names` → `python3 asr_v2.py names en`. Раньше распозналось нормально (кроме «Hello! You... you!» → «tello»: при желании перефразировать, например «Hi! Hello! You... hi!»).
5. `python3 timeline_v2.py names && bash build_audio.sh names` — смотреть длительность (цель 1:50–2:10, но лучше короче: хук ≤ 4–5 с).
6. Превью: `python3 prev_v2.py names "0;S['a1_x']['t']+0.5;SC['C2']['ev']['ring']+0.5;SC['outro']['s']+5" sheet.png`. Допилить: руки Дейва при объятии выглядят вяло; блик кольца на C2 мелкий.
7. `bash render.sh names` → `out/names.mp4`; проверка: ffprobe, `ffmpeg -af ebur128` (−14 LUFS), раскадровка `fps=1/4,tile`.
8. Положить видео в `speak_in_english/releases/names.mp4`, закоммитить и отправить в ветку `claude/engine-setup-market-rebuild-yxns46`.

Не трогать: ветку `claude/vigilant-clarke-w5ngd0` (серия 4 основного канала).
