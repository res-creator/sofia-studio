## 2. ElevenLabs: почему озвучки ещё нет

Проверка 29.10.2026 (`GET /v1/user/subscription`): тариф free, использовано 4 268 из 10 000, **осталось 5 732 символа**. Лимит обновится 25.11.2026. Докупить символы на бесплатном тарифе нельзя (`can_extend_character_limit: false`).

Расход (английские реплики eleven_v3 считаются вместе с тегами вроде `[smug]`, диктор Sarah идёт одним дублем с `<break>`):

| Серия | Английские реплики | Bella | Sarah (дубль) | Итого |
|---|---|---|---|---|
| rich | 1 575 | 53 | 711 | **2 339** |
| busy | 1 437 | 45 | 705 | **2 187** |
| avoidparty | 1 577 | 69 | 731 | **2 377** |
| **Всего** | | | | **6 903** |

На три серии не хватает **≈1 200 символов**, с запасом 10 % на возможную пересъёмку — ≈1 900. Кроме того, параллельно в производстве другая партия. Если она возьмёт свою долю из тех же 5 732, понадобится почти вся сумма: ≈6 900–7 600 символов. Поэтому по правилу задания платная генерация **не запускалась**, альтернативные голоса не использовались.

## 4. Длительность (оценка до озвучки)

Скорость речи откалибрована по прошлым сериям (англ. ≈13.8 симв/с, диктор ≈16 симв/с, поправка ×0.94 по факту прошлой партии):

| Серия | Оценка |
|---|---|
| rich | ≈2:50 |
| busy | ≈2:40 |
| avoidparty | ≈2:50 |

⚠️ Это больше цели 1:45–2:15. Причина в длине сценариев: в серии 40–49 реплик, одна только речь занимает ≈2:15. Паузы под гэги уже ужаты. Голоса не ускорены, длинных объяснений диктора нет: у диктора 1–2 короткие фразы на уровень. Чтобы выйти на 2:15, нужно сократить сами сценарии: убрать примерно по 8–10 реплик на серию. Без согласия владельца это не делалось.

## 5. Раскадровка (кратко)

### rich: парковка у кафе «CAFÉ ROYAL», красная спорткар-аренда, справа старая машина героя
- **Хук:** обложка (Кевин в белом костюме и очках у красной машины, плашка MILLIONAIRE?!) → реплики → вставка ключа с биркой RENTAL — RETURN BY 6 PM → рука прячет бирку.
- **A1:** нажимает брелок → мигает и воет соседняя дешёвая машина (УИ-У!) → прячет брелок за спину. Карточка meter.
- **A2:** показывает часы → вставка часов: LOW BATTERY 1% → BLUETOOTH DISCONNECTED → TOY MODE, игрушечная мелодия → «They're… very modern», пот.
- **B1:** телефон: MOM CALLING → мама из трубки про мусор → «Mom! I'm in a business meeting!» → друг смотрит, плашка «ДЕЛОВАЯ ВСТРЕЧА?».
- **B2:** уведомление CAR RENTAL: ends in 15 minutes → смахивает → «Absolutely.», пот.
- **C1:** друг щурится → «Fair enough» → достаёт телефон → вставка номера RENT 001 / STEVE'S RENTALS → герой застыл (тиканье).
- **C2:** «That car belongs to me» (тишина музыки) → вставка брони: CUSTOMER KEVIN BROWN, 3 HOURS, $49.99, APPROVED by Steve → снимает очки → «For three hours, it was» → рука → ключи → машина уезжает (ВЖУХ!) → прохожий: «Nice car!» про старую машину → «That one's actually mine» → брелок, жалкое «пи-пи…» → чёрный экран → карточка C2.

### busy: офис, стол героя (монитор, стопка бумаг, песочные часы), начальник рядом
- **Хук:** обложка (на мониторе игра, плашка VERY BUSY!) → шаги «ТОП-ТОП-ТОП» → закрывает игру → бешено печатает → реплики → вставка монитора I AM WORKING ×9.
- **A1:** перекладывает одни и те же бумаги («ШУРШ-ШУРШ»).
- **A2:** начальник приходит и уходит → выдох → вставка песочных часов BREAK TIME.
- **B1:** стопка до потолка → прижимает бумаги к груди → лист падает → вставка TO-DO LIST: LOOK BUSY / DRINK COFFEE / LOOK BUSIER → начальник смотрит на лист.
- **B2:** вставка PROJECT REPORT — 200 PAGES → «Two hundred pages?» → начальник тянется к мышке, пот.
- **C1:** вставка: страницы летят, PAGE 1…200 / 200, на каждой I AM WORKING → спор → пауза.
- **C2:** начальник скрещивает руки → сотрудник встаёт и говорит речь частями (тишина) → «That's… actually quite impressive» → «Even better» → склейка на сцену: экран CORPORATE PRODUCTIVITY SEMINAR / AUDIENCE: 500 PEOPLE, зал, микрофон → «Please welcome…» → аплодисменты → слайд HOW TO LOOK BUSY WITHOUT WORKING → «…I should have just done my work.» → чёрный экран.

### avoidparty: гостиная (диван, плед, телефон) ↔ подруга Кейт на своей вечеринке ↔ входная дверь ночью
- **Хук:** обложка (героиня в пижаме под пледом, плашка PARTY? NO, THANKS) → звонок → Кейт на вечеринке / героиня на диване → склейка: дверь, толпа с шарами, «SURPRISE!» → крупно лицо в ужасе.
- **A1:** зевает → смотрит на диван (искорки, «УЮТНО…»). Карточка meter: желание идти 0 %.
- **A2:** смотрит на пижаму → вставка телефона DRESS CODE: PAJAMAS → закрывает глаза.
- **B1:** вставка-фантазия: она с ноутбуком в QUIET CORNER среди танцующих, плашка WORK FROM PARTY.
- **B2:** кашляет → «To your house!» → застыла (тиканье).
- **C1:** улыбка облегчения → напряглась → вставка CALL ENDED → «ДИНЬ-ДОН!».
- **C2:** дверь: Кейт и толпа (шары, колонка, торт, танцор) → речь Кейт частями → «Under no circumstances…» (тишина) → гости проходят внутрь → гость с договором → вставка PARTY VENUE RENTAL AGREEMENT / HOST: YOU / CLEANING FEE: $500 → «Why am I paying for this?!» → закрывает дверь не с той стороны: она снаружи, в окнах мигает вечеринка, чек-лист PARTY INSIDE ✓ / HOMEOWNER OUTSIDE ✓ → «…I live here.» → чёрный экран.

Концовка у всех: `K.outro`, шпаргалка из 4 фраз (A2, B1, C1, C2), вопрос зрителю, кнопка подписки с курсором.

## 6. Как запустить, когда будут символы (из `speak_in_english/engine`)

```bash
bash setup.sh                        # только в новом контейнере (npm, python, модели Whisper для проверки на слух)
bash finish_batch_rbp.sh             # все три серии по очереди; или: bash finish_batch_rbp.sh rich
```

Перед каждой серией скрипт проверяет баланс и останавливается, если символов не хватает. Уже сгенерированные реплики не генерируются повторно. Дальше по каждой серии: посмотреть `eps/<slug>/asr.txt` и раскадровку `ffmpeg -i ../releases/<name>.mp4 -vf "fps=1/4,scale=216:384,tile=8x6" -frames:v 1 sheet.jpg`, затем закоммитить и запушить.
