# «На всякий случай», выпуск 1 — скетч «репетитор и ученица» (плоский стиль Ани)

Сюжет: Катя перед поездкой в Нью-Йорк просит репетитора научить её абсурдным фразам «на всякий случай»; через неделю на таможне все они пригождаются.
Стиль: `people_flat.js` (Аня из «От вежливого до грубого» + новые персонажи: репетитор, таможенник), `flat.js`.
Монтаж по референсу the.seventh: один герой в кадре, наезды, крупные субтитры кусками, плашка серии сверху.
Голоса: ElevenLabs eleven_v3 с эмоциями (Катя — русская модель, читает английский транслитом = акцент).
```
python3 voice/gen.py && python3 voice/stt.py
for i in 0 1 2 3; do node render.js chunk $i 4 & done; wait
node render.js audio && node render.js srt && node render.js cover 72
```
