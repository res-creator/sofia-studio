## Финальная карточка «РУССКИЙ ДЛЯ БРУК»
- АВОСЬ — fingers crossed · maybe it'll work out
- НОРМАЛЬНО — it's fine · not bad
- ДАВАЙ — bye · come on · let's
- ОЙ ВСЁ — I'm done · whatever
- Я НА МЕЛИ — I'm broke
- ОПАЗДЫВАЮ — I'm running late
- УЖЕ ЕДУ — I'm on my way

Вопрос: «Какое русское слово НЕ переводится на английский? Авось? Ой всё? Своё? Пишите в комменты».

## Мини-шутки по словам (схема «объяснение → попытка Брук → развязка»)
1. **Авось:** Брук применяет его к нестерильной пилке, Жанна отдёргивает руку: «Авось — не на моих ногтях!»
2. **Нормально:** каламбур «Normal… no?», потом практика. На «как дела?» Брук отвечает «Нормально!» и перечисляет катастрофы. Жанна: «Идеально. Ты русская».
3. **Давай:** Брук выдаёт все три значения подряд, плашки на карточке загораются по очереди. Жанна: «Нормально!» (повтор слова из урока 2).
4. **Ой всё:** у Брук сначала выходит робко, с вопросом. У Жанны Петровичу — только «ok». Голосовое Брук — три ответа, кольцо и колокольчик. Жанна просит урок у Брук, Брук: «Нормально, hun» + поп.

## Заметки для сборки (позже)
- Музыку не добавлять (координатор кладёт варианты сам); только SFX.
- Никого не резать краем кадра: в крупных планах персонаж целиком по ширине, руки с пилкой и телефоном внутри кадра.
- Петрович не появляется: только чат и колокольчик за кадром.
- Мини-карточка «BROOK'S DAY» и плашки «давай» держатся ≥ 1.2 с.
