## Правила для Shorts (как лучше)
- Вертикальное видео до 3 минут. Все ролики ниже подходят, кроме полных `tour_guide` (3:07) и `one_good_photo` (3:10). Для них взяты сокращённые версии.
- Название до 100 символов; главное (вопрос «Как сказать…») в начале, потому что в ленте видно только первые 40–60 символов.
- Хештеги: YouTube показывает только первые 3 над названием. Поэтому в описании сначала `#shorts #английский #английскийязык`, а затем 1–2 тематических.
- В первой строке описания идёт крючок (ситуация), дальше фразы для сохранения и вопрос зрителю: так делает ролик, который собирает комментарии.
- Закреплённый комментарий берите из файла `*_tiktok.md` рядом с каждым новым роликом (там уже есть первый вариант фразы).
