# Проба нового стиля (как у референсов владелицы): чистый вектор + их манера монтажа

- `flat.js` — набор: один толщины тёмный контур, плоские цвета, тень одной полосой, большие круглые глаза; персонаж (голова+торс), субтитры-фразы.
- `render.js` — 18 с пробы «Первый созвон на английском»: жёсткие склейки каждые 1,5–2 с, медленный наезд/отъезд, вставка (палец жмёт кнопку), метафора (Аня → кактус «я мебель»), невидимка (прозрачность), резкий наезд на «Что?», субтитры по фразам.
- Запуск: `node render.js still 5,9` или `node render.js video` → out/flat_style_test.mp4
