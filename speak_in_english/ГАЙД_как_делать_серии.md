# «… на каждом уровне английского» — полный гайд по производству

**Для кого:** для ИИ-помощника, который будет делать эти ролики для TikTok-канала **@speak_in_english**.
**Что внутри пакета:**

| Папка / файл | Что это |
|---|---|
| `ГАЙД_как_делать_серии.md` | этот документ |
| `engine/` | весь движок: рисовка персонажей, анимация, интерфейс, голоса, звук, сборка видео. Это тот самый код, которым сделаны все ролики |
| `engine/episodes_v2.py` | сценарии **всех 8 серий** — лучшие образцы текста |
| `engine/airport.js`, `market.js`, `london.js`, `party.js` | рендеры 4 последних серий. Это шаблоны для новых серий |
| `engine/eps/<серия>/nar_all.mp3` | готовые дубли диктора для этих 4 серий. С ними можно пересобрать любую из них и проверить, что всё работает |
| `examples/episode_template.py` | пустой шаблон сценария с комментариями |
| `examples/narrator_takes.md` | тексты диктора всех серий в том виде, в каком их вставляли в ElevenLabs |
| `references/` | обложки, раскадровки 4 серий, все элементы интерфейса, все персонажи с их голосами |

Опубликованные ролики канала — тоже референс. Смотри прежде всего «Соседи», «Лондон», «Аэропорт» и «Рынок».

---

## 1. Что это за формат, в одной фразе

Одна бытовая ситуация, которую знают все: попросить соседей сделать музыку потише, сдать чемодан с перевесом, поторговаться на рынке. Героиня проходит её **6 раз, на каждом уровне английского от A1 до C2**. Каждый раз она говорит одну фразу, и по ней видно уровень. Каждый уровень — новый собеседник и новый визуальный гэг. Русский диктор объясняет, что было не так или что запомнить. На C2 героиня выдаёт вычурную речь, и в конце получается **неожиданный поворот**.

Цель ролика: зритель смеётся, узнаёт себя («я так и говорю, как А2»), запоминает 3–5 фраз, пишет свой вариант в комментарии и подписывается.

## 2. Технические требования к ролику

| Параметр | Значение |
|---|---|
| Формат | вертикальное видео 9:16, **1080×1920**, 30 fps |
| Длина | **от 1:50 до 2:10**. Минимум строго больше 1:00: на канале монетизируются только видео длиннее минуты. Карусели не монетизируются, поэтому делаем только видео |
| Кодек | H.264 (yuv420p), звук AAC 160 kbps, `-movflags +faststart` |
| Громкость | −14 LUFS, true peak −1.5 dB (ffmpeg `loudnorm=I=-14:TP=-1.5`) |
| Размер файла | около 28 МБ на 2 минуты: 2-pass, ~1600 kbps. Так файл проходит в чат до 30 МБ. Для самого TikTok лимит намного больше |
| Водяной знак | `@speak_in_english`, мелко, внизу по центру |
| Язык | диктор, карточки и субтитры на русском. Реплики персонажей на английском, в пузыре под ними русский перевод |

**Безопасные зоны TikTok.** Справа (x > 950) висят кнопки, снизу (y > 1680) подпись, сверху (y < 150) вкладки. Всё важное держим в центре. Обложка в сетке профиля обрезается до центрального прямоугольника 3:4, примерно **y 240–1680**: ключевой текст обложки должен быть там.

## 3. Структура серии по секундам

Это пример «Аэропорта», 2:06. Остальные серии устроены так же.

```
0:00–0:11  ХУК / ОБЛОЖКА  (диктор ~9–10 с)
0:11–0:23  A1   заставка уровня 1.15 с → героиня → собеседник → гэг → диктор + карточка
0:23–0:35  A2   … + английская подсказка (tip) розовой плашкой
0:35–0:49  B1
0:49–1:04  B2   … + tip
1:04–1:24  C1   … + tip
1:24–1:56  C2   длинная речь → пауза «думает» (тиканье) → панчлайн → короткий ответ героини → мораль
1:56–2:06  КОНЦОВКА: вопрос зрителю, 4 фразы-плашки, «ПИШИ В КОММЕНТЫ», кнопка «ПОДПИСАТЬСЯ» → «ТЫ С НАМИ!»
```

Уровни длятся примерно так: A1 ~11 с, A2 ~12 с, B1 ~13–14 с, B2 ~15 с, C1 ~19 с, C2 25–32 с. C2 — кульминация, на неё времени не жалеем.

### 3.1. Хук и обложка (самое важное для просмотров)

- **Кадр 0 = обложка.** Он должен быть полностью собран с первого кадра: без затемнения, без «выезда» элементов. Его видят в ленте, в сетке профиля и на первом кадре автоплея. Прочитать обложку нужно за **1 секунду**. Движение добавляем мелкими вещами: что-то качается, мигает, пролетает самолётик.
- На обложке крупный заголовок из 3–4 строк. Главное слово розовое и самое большое. Примеры:
  - «ЧАС НОЧИ / У СОСЕДЕЙ / **ВЕЧЕРИНКА** / ЧТО СКАЖЕШЬ?»
  - «ЧЕМОДАН / **29 КГ** / А МОЖНО 23 / ЧТО СКАЖЕШЬ?»
- **Каждая серия начинается по-новому.** Это требование Станислава: «у нас все видео одинаково начинаются, поменяй». Уже были такие открывашки:
  1. «Соседи»: спальня в час ночи, часы 01:00, злая героиня в пижаме и маске для сна против рокера Рокки, летят ноты.
  2. «Лондон»: экран разрезан по диагонали, A1 «Station? Choo-choo?» против C2 «Pardon the intrusion…», значок VS, едет даблдекер.
  3. «Аэропорт»: табло вылетов с перекидными буквами (split-flap), а внизу гигантский чемодан на весах «29.0 KG» и табличка «MAX 23 KG».
  4. «Рынок»: огромный качающийся ценник с зачёркнутыми £100 → £50 → £20 и обведённым «£5?!». На слове «кусается» ценник дёргается, появляется «КУСЬ!».

  Следующие идеи: экран телефона с перепиской, школьная доска, обложка журнала, меню ресторана, экран навигатора, чек из магазина, табло «Кто хочет стать миллионером».
- Текст диктора в хуке всегда по формуле:
  **«<Ситуация одной-двумя фразами>. Как <сделать X> на английском? По одной фразе видно твой уровень. Проверим!»**
- На слове «Проверим» падает штамп «ПРОВЕРИМ!» со звуком печати. Примерно на 2.5 с снизу вверх выезжает полоска уровней A1–C2.

### 3.2. Один уровень

1. **Заставка уровня, 1.15 с.** Круг цвета уровня раскрывается на весь экран, на нём «уровень **A1** BEGINNER», потом круг улетает в полоску наверху. Звуки: whoosh и impact.
2. **Героиня говорит фразу.** Камера на неё крупно. Пузырь появляется у её головы: английский текст печатается по буквам, ниже розовым русский перевод.
3. **Собеседник отвечает.** Камера на него. Пузырь справа с именной плашкой (TOM, ROCKY…).
4. **Гэг.** Визуальная шутка на 1–3 секунды со звуком. Камера отъезжает на общий план.
5. **Диктор.** Внизу субтитры по 3 слова, КАПСОМ, текущее слово жёлтым. Сверху выезжает карточка урока (типы карточек — ниже).
6. **Подсказка (tip).** Только A2, B2 и C1. Правильная английская фраза звучит голосом «учительницы» (Kokoro af_bella) и висит розовой плашкой внизу. Перед ней диктор говорит «Правильно так:» или «Запоминай:».

### 3.3. Концовка

- Розовый фон с косыми полосками. Снизу выезжают героиня и 2 персонажа серии и машут.
- Заголовок: «А КАК <СКАЖЕШЬ/СПРОСИШЬ/ТОРГУЕШЬСЯ> ТЫ?»
- 4 плашки-фразы. Первая — фраза A1, серая и зачёркнутая. Остальные три — лучшие фразы B1, B2 и C1 в цветах уровней.
- «ПИШИ В КОММЕНТЫ» со стрелкой.
- На слове «подпишись» появляется кнопка «ПОДПИСАТЬСЯ». К ней подъезжает **курсор-стрелка** и нажимает, кнопка становится «ТЫ С НАМИ!», разлетаются звёздочки.

  ⚠️ Только курсор! Нарисованный палец получился похожим на средний палец, и Станислав попросил больше так не делать.
- Текст диктора всегда: **«А как ты <…>? Пиши свою фразу в комментарии! И подпишись, впереди ещё много новых серий.»**

## 4. Как писать сценарий (самое главное)

### 4.1. Выбор темы

- Ситуация, с которой сталкивался каждый, и с понятным конфликтом: что-то нужно получить, отказаться, пожаловаться, договориться.
- В ситуации должно быть место для **6 разных собеседников**. Это «станции» на одной улице, в одном терминале, на одном рынке, на одной вечеринке.
- Должен быть **визуальный гэг**: предмет, цифра, ценник, весы, громкость.
- Нужен **сильный поворот на C2**.

**Уже сделано, не повторять:**
- серии v1: заказ кофе; жалоба в отеле; такси; опоздание к боссу;
- серии v2: спортзал («ты ещё долго?»); лифт (ответ на How are you); бабушкина добавка; парикмахерская («подстричь кончики»); соседи с вечеринкой; дорога в Лондоне (King's Cross); аэропорт (перевес чемодана); блошиный рынок (торг).

**Идеи на будущее, пока свободны:**
- в ресторане принесли не то блюдо;
- вернуть вещь в магазин без чека;
- собеседование: «Tell me about yourself»;
- первое свидание: как вежливо уйти;
- в самолёте сосед занял подлокотник;
- соседка по квартире не моет посуду;
- попросить пароль от Wi-Fi в кафе;
- попросить незнакомца сфотографировать;
- подарок не понравился: как сказать «спасибо»;
- опоздала на поезд: пропустите без очереди;
- позвонить в поддержку интернета;
- попросить повышение;
- small talk о британской погоде;
- отказаться от второго свидания;
- заблудилась в IKEA;
- забыла имя знакомого.

Медицинских тем с советами избегаем.

### 4.2. Формула уровней

| Уровень | Что говорит героиня | Как это работает в сюжете | Карточка |
|---|---|---|---|
| **A1** | 2–4 слова телеграфом, часто с жестом или хитростью: «Music. No. Sleep!», «Bag. Good. Twenty-three!», «This. Cheap? Cheap?» | Смешное недопонимание. Рокер услышал только «no sleep» и позвал тусить. Агент заметил, что она держит чемодан рукой. Продавец понял, что перед ним турист, и удвоил цену | `meter`: «ГРАММАТИКА 0%» + шуточная шкала («ХИТРОСТЬ ✗ спалилась», «ЦЕНА ✗ выросла вдвое») |
| **A2** | Целое предложение с **одной типичной ошибкой русскоговорящих**: пропущены do или to («How much I pay?», «I want cut…»), без артикля («Where is station?»), грубый императив («Stop it!»), ложный друг («I'm fed up» вместо «I'm full») | Собеседник реагирует на ошибку. Диктор называет её, tip даёт правильный вариант | `swap`: ошибка зачёркнута, ниже галочка и правильная фраза |
| **B1** | Простая вежливая стандартная фраза: «Excuse me, could you…?», «Can I…?», «Is that your best price?» | Работает, но с маленьким гэгом: бабушка крутит громкость не в ту сторону, из чемодана летят арбуз, сковородка и садовый гном | `eq`: фраза = перевод, пояснение, штамп в 2 строки («ГЛАВНАЯ ФРАЗА») |
| **B2** | Идиома или фразовый глагол: keep it down, knock a bit off, excess baggage fee, point me in the right direction | Часто панчлайн от собеседника («Sure. Pack less next time.» и звук «ба-дум-тсс») | `big`: розовая плашка-выражение = перевод, пример и иконка |
| **C1** | Естественный «как у носителя» английский со смягчениями: «Sorry to bother you, but…», «Is there any chance you could let it slide?», «It's a bit out of my price range. Would you take forty?» | Почти всегда срабатывает, вежливо и красиво. Или упирается в «rules are rules» | `eq` + 2 примера с переводом |
| **C2** | Длинная вычурная речь на 20–30 слов с 2 редкими словами: implore, modicum, cacophony, provenance, killjoy, prevail upon | **ПОВОРОТ.** Собеседник не понял ни слова, или речь не сработала, но сработало что-то другое, или всё вышло наоборот. Потом пауза «*X думает*» с тиканьем, сухой панчлайн, короткий ответ героини в 1–3 слова | `c2`: 2 слова с переводом, потом мораль капсом в 3 строки |

**Повороты на C2, которые уже были** (по ним видно сам принцип):
- **Соседи:** рокер — «Cool speech. So... wanna come in?», она — «Is there pizza?». Мораль: «НЕ МОЖЕШЬ ПОБЕДИТЬ — ПРИСОЕДИНЯЙСЯ!». **Эта серия зашла всем лучше всего**, на неё и равняемся.
- **Аэропорт:** речь не сработала. Тогда она за 3 секунды надевает на себя всю одежду из чемодана: свитера, шарфы, три шапки и очки. Весы показывают 23, и она уходит вразвалочку. Мораль: «НЕ МОЖЕШЬ ДОПЛАТИТЬ — НАДЕНЬ ВСЁ!»
- **Рынок:** она так раскритиковала вазу, что антиквар отдал её даром и ещё доплатил £10. Мораль: «C2 — ЭТО КОГДА ТЕБЕ ЕЩЁ ДОПЛАЧИВАЮТ».
- **Лондон:** пафосный вопрос, где King's Cross. Мальчик: «It's behind you.» Огромный вокзал за её спиной и стрелка «ВОТ ЖЕ ОН!».
- **Спортзал / Парикмахерская / Лифт:** длинная речь, а в ответ «So... you want the bench?», «So... just a bob?», «I just said hi.».

### 4.3. Правила юмора

- **Конкретно и физически.** Не «ей отказали», а табло показывает £75, ценник переворачивается с £20 на £40, весы мигают красным 29.0.
- **Эскалация.** К C2 ставки растут.
- **Каменные лица.** Собеседник реагирует невозмутимо, и от этого смешнее.
- **Звуки как знаки препинания:** касса «дзынь», «ба-дум-тсс», бойнг, стук, тиканье в паузе, фанфары.
- **Британский колорит:** quid, mate, love, darling, dear, tenner, «Oh, go on then».
- **Последняя реплика C2 короткая и сухая:** «The bench.», «Is there pizza?», «Pleasure doing business.»
- Юмор добрый. Никого не унижаем, без политики и без стереотипов о народах.
- **Повторяющиеся персонажи** делают из роликов сериал: Рокки, Марго, Нана, Агнес, Реджи, Марк, Прия. Рокки — любимчик, часто именно он делает поворот на C2.

### 4.4. Правила текста диктора (русский, ElevenLabs)

- Уровни пишем словами, чтобы голос читал правильно: **«Уровень А-один», «А-два», «Би-один», «Би-два», «Си-один», «Си-два»**. «Уровень» говорим только на A1.
- Числа тоже словами: «двадцать девять килограммов».
- Английские выражения прямо в русском тексте можно, Sarah читает их нормально. Перевод даём в ёлочках: «Knock a bit off, «скинуть немного».»
- Перед подсказкой говорим «Запоминай:» или «Правильно так:».
- Одна реплика диктора — 1–3 короткие фразы, примерно 4–8 секунд. Весь текст диктора за серию ~800–1000 символов.
- Букву «ё» ставим везде («ещё», «всё»): так её правильно произносит голос.

### 4.5. Правила английских реплик

- Английский должен быть **правильным и естественным**. Неправильно только там, где это задумано (A1, A2). Британский или американский выбираем по сеттингу, в Лондоне британский.
- Ошибка в A2 — та, которую реально делают русскоговорящие.
- Реплики персонажей короткие: 3–10 слов. Длинная только речь героини на C2.
- Каждую фразу проверяем на естественность: так ли сказал бы носитель.
- Сложные слова на C2 должны быть настоящими и подходящими по смыслу. Перевод в карточке короткий: «= умолять», «= хоть капля».

### 4.6. Перевод в пузырях

Под каждой английской репликой даём живой разговорный русский перевод, не дословный. Тон тот же: «Five? That's not haggling, dear, that's robbery!» → «Пять? Это не торг, милая, это грабёж!»

## 5. Голоса

### 5.1. Русский диктор — ElevenLabs

- **Голос:** Sarah — Mature, Reassuring, Confident. Это стандартный голос библиотеки ElevenLabs, `voice_id = EXAVITQu4vr4xnSDxMaL`.
- **Модель:** **Eleven Multilingual v2**. Настройки близки к стандартным: Stability ≈ 50%, Similarity ≈ 75%, Style Exaggeration 0, скорость чуть выше середины ползунка.
- **Как генерировать:**
  1. Весь текст диктора за серию генерируем **одним дублем**: хук, 6 реплик уровней и концовку, разделённые `<break time="2.0s" />`. Так голос звучит ровно, а `split_nar.py` сам разрежет дубль на 8 кусков по самым длинным паузам.
  2. Готовый текст печатает `python3 nar_take.py <серия>`. Примеры всех серий лежат в `examples/narrator_takes.md`.
  3. Скачиваем mp3 и кладём его в `engine/eps/<серия>/nar_all.mp3`.
  4. Запускаем `python3 split_nar.py <серия>` — получаются `vo/hook.wav … vo/outro.wav` и тайминги слов для субтитров.
- **Расход:** 1 символ ≈ 1 кредит, на серию ~800–1000 кредитов.
- **Если сайт завис на «Loading…»** после Generate (так бывало часто): кредиты уже списались, и аудио готово. Перезагрузи страницу, открой вкладку **History** справа и нажми на последний пункт — аудио появится в плеере, его можно скачать.
- **Через API.** Если у помощника есть API-ключ, можно запустить `ELEVENLABS_API_KEY=... python3 eleven_nar.py <серия>`. Голос, модель и паузы там те же. Ключ берётся только из переменной окружения, в файлы его не писать. Мы сами делали через сайт, поэтому этот скрипт в работе не тестировался.

### 5.2. Английские голоса — Kokoro

[Kokoro-82M](https://github.com/thewh1teagle/kokoro-onnx) — открытая модель синтеза речи. Бесплатная, работает локально и звучит естественно. Станислав просил: **никаких роботизированных голосов** (Piper/espeak и подобные запрещены).

Голоса задаются в начале `engine/episodes_v2.py` в словаре `CAST`: `voice`, `speed` и при необходимости `pitch` (сдвиг в полутонах). Генерация: `python3 tts_v2.py <серия>` создаёт `eps/<серия>/vo/<id>.wav`.

- Пожилые: скорость 0.86–0.92 и pitch от −1 до −1.4. Дети: `af_sky` или `am_echo` с pitch +3. Здоровяки: `am_onyx` с pitch −1.5.
- В одной серии у всех персонажей разные голоса.
- Естественная подача: короткие предложения, «...» для паузы, «!» для акцента, числа словами (twenty-three), без сокращений.

### 5.3. Проверка на слух (обязательно)

`python3 asr_v2.py <серия> en,ru` прогоняет каждую реплику через Whisper и печатает, что он услышал.
- Если английскую реплику распознало неверно, **перефразируй её и сгенерируй заново**, не надейся, что пронесёт.
- В русском дикторе Whisper иногда пишет «C1» вместо «Си-один» или путает английские вставки. Это нормально. Смотрим только на то, чтобы смысл и слова совпадали.

### 5.4. Музыка и звуки

Всё синтезируется кодом в `audio_v2.py` (numpy), поэтому никаких проблем с авторскими правами.
- **Музыка:** у каждой серии свой стиль. В «Соседях» на каждом уровне свой жанр (рок, EDM, вальс, барабаны, диско). Лондон — пиццикато. Аэропорт — лаунж-босса. Рынок — хонки-тонк пианино.
- **Ducking:** под голосом музыка автоматически приглушается на ~70%.
- **Тишина на C2:** музыка **полностью замолкает** от конца речи героини до панчлайна. Так пауза работает на комедию.
- **Готовые эффекты:** whoosh, impact, pop, stamp, ding, buzz, tick, boing, thud, clank, register (касса), rimshot (ба-дум-тсс), gasp, zip, squeak, tada, riff (гитарный рифф), coo (голубь), bark, umbrella, sparkle, scratch (пластинка), deflate (грустный тромбон) и другие. Новый эффект — это функция в `audio_v2.py` плюс запись в словаре `SFX`.

### 6.4. Обязательные правила рисовки (просьбы Станислава)

1. **Руки гнутся естественно.** Локти никогда не выворачиваются назад. Любая поза руки делается через `reach()` из `pose.js`: задаёшь, куда тянется кисть, а модуль сам ставит локоть естественно.
2. **Волосы за шеей и плечами**, а не поверх шеи. Движок уже рисует задние волосы до тела, ничего не ломай.
3. **Каждая серия начинается по-новому** (раздел 3.1).
4. **Никаких жестов, похожих на средний палец.** На кнопке подписки только курсор `UI.tapCursor`.
5. **Ролик длиннее минуты**, лучше около двух.
6. **Русский диктор — Sarah**, английские голоса Kokoro, ничего роботизированного.

### 6.5. Интерфейс (уже реализован в `ui_v2.js`)

- **Полоска уровней** наверху (y≈222): текущий уровень пульсирует, пройденные с галочкой.
- **Пузыри** у головы говорящего: английский печатается по буквам, ниже розовый перевод. У собеседника цветная плашка с именем.
- **Субтитры диктора** на y≈1470: по 3 слова, КАПСОМ, Unbounded, текущее слово жёлтое `#FFE15A`, обводка оливковая.
- **Подсказка tip**: розовая плашка с белым английским текстом на том же месте.
- **Карточки урока** выезжают сверху (y 330–800), пока говорит диктор. Типы карточек: `meter`, `swap`, `eq`, `big`, `c2` (примеры в `references/ui_elements.jpg`).
- **Заставки уровней**, **водяной знак**, **штамп** «ПРОВЕРИМ!».

### 7.3. Персонаж в коде

Внешность задаётся в `cast_v2.js`:

```js
rocky: { kind: 'human', h: 1760, skin: '#EBB896', iris: '#3A2A1A', jaw: 1.25,
  hair: { style: 'long', col: '#7A4E2E', len: 1.35 }, stubble: '#5A3A22', mustache: '#5A3A22',
  build: { shoulder: 1.3, belly: 0.55, arm: 1.3 },
  top: { type: 'tank', col: '#22252E', text: 'ROCK\nNIGHT', textCol: '#E0474C' },
  bottom: { type: 'jeans', col: '#3A4050' }, shoes: { col: '#1E2128' } }
```

Доступные варианты:
- **Причёски:** bob, long, curly, bun, ponytail, highpony, bouffant, short, buzz, quiff, baldsides.
- **Верх:** tee, longsleeve, sweater, polo, tank, kidtee, hoodie, gymtop, tracksuit, blazer (с галстуком), coat, cardigan.
- **Низ:** trousers, jeans, leggings, joggers, shorts, skirt.
- **Аксессуары:** glasses, mustache, beard, stubble, earrings, necklace, headband, cap.

Шляпы, береты, фартуки, бейджи и прочее рисуются в рендере через колбэки `st.front` (поверх головы) и `st.afterTorso` (поверх тела, под руками).

Поза в кадре задаётся состоянием `st`:

```js
const g = geom(CAST.rocky);
human(ctx, CAST.rocky, {
  t, talk: talk('rocky', t),            // рот открывается по громкости его реплики
  mood: 'happy',                        // neutral happy smug worried shock skeptical bored sad angry annoyed surprised tired
  turn: 0.35, look: 0.8, lookY: 0,      // поворот головы и взгляд
  armL: reach(g, -1, -g.sw * 1.05, -850),   // левая кисть к точке (x, y) от ступней
  armR: reach(g,  1,  g.sw * 2.4, g.ySh - 260),
  items: { R: items.teacup() },         // предмет в руке
  legPose: 'stand',                     // stand walk wide squat sit
});
```

### 7.4. Монтажный лист (`timeline_v2.py`)

Для каждой серии пишется ветка `LV` — список уровней. Каждая строка: `(id реплики, пауза перед ней в секундах, [звуки/события])`. Пример из «Аэропорта»:

```python
A1=[("a1_her", 0, [("LIFT", -0.35, 0), ("strain", -0.3, 0.5)]),
    ("a1_x", 0.45, []),
    ("a1_nar", 1.15, [("DROP", -0.95, 0), ("thud", -0.9, 0.9), ("buzz", -0.72, 0.65)])],
```

- **Пауза** перед репликой — это время на гэг. Здесь 1.15 с перед диктором: за это время героиня отпускает чемодан, звучит «бух» и весы показывают 29.0.
- **Звук** задаётся как `("имя", смещение, громкость)`. Смещение отсчитывается от начала реплики (минус — раньше неё), или от конца реплики: `("e", 0.05)`.
- **СОБЫТИЕ** — имя КАПСОМ. Оно не звучит, а записывает момент в `scene.ev`, и рендер по нему рисует действие (`ev.drop`, `ev.tag`, `ev.dress`…).
- `TICKS(2.4)` — тиканье часов в паузе C2. `INTRO = 1.15` — длительность заставки уровня.
- После правок запускаем `bash build_audio.sh <серия>`: печатается длительность серии, проверяем, что она 1:50–2:10.

### 7.5. Рендер серии (`<серия>.js`)

Копируй `market.js` или `airport.js`: это самые свежие шаблоны, в них учтены все правила. Что меняется под новую серию:

1. `TL` — путь к `eps/<серия>/timeline.json`, в конце `E.run('<серия>', …)`.
2. `WHO` (кто собеседник на каждом уровне), `ST` (где на «улице» стоит каждая станция, шаг 2600) и `NAMES` (плашки с именами).
3. **Задник** (`drawStreet` / `drawTerminal`): рисуется один раз и размывается.
4. **Предметы станции:** прилавок, стойка, весы, ценники, мебель.
5. **Поведение персонажей** по уровням: `herState()` и функция собеседника. Эмоция, руки, предметы в руках меняются по времени реплик (`SP.a1_x.t`, `endOf('a1_x')`) и по событиям (`ev.drop`).
6. **Камера** `shotFor(t)`:
   - `herC` — крупно героиня, `othC` — крупно собеседник, `two` — общий план;
   - на гэгах — свои планы;
   - `cut: true` — резкая склейка.
7. **Открывашка** `drawHook()`: новая для каждой серии, кадр 0 полностью собран.
8. **Концовка** `drawOutro()`: вопрос, 4 плашки, кнопка с курсором.
9. Подписи в кадре вроде «*Рокки взвешивает*», «БА-ДУМ-ТСС!», «+£10» добавляются в `renderFrame()`.

### 7.6. Порядок работы над новой серией

```
1. Сценарий         → EP["slug"] в episodes_v2.py (+ новые персонажи: голос в CAST, внешность в cast_v2.js)
2. Англ. голоса     → python3 tts_v2.py slug ; python3 asr_v2.py slug en   (перефразировать всё, что не распозналось)
3. Диктор           → python3 nar_take.py slug → ElevenLabs (Sarah, Multilingual v2) → eps/slug/nar_all.mp3
                      python3 split_nar.py slug ; python3 asr_v2.py slug ru
4. Монтажный лист   → ветка LV в timeline_v2.py (паузы под гэги, звуки, СОБЫТИЯ)
5. Звук             → ветка музыки в audio_v2.py (+ новые эффекты) ; bash build_audio.sh slug
6. Рендер-файл      → cp market.js slug.js и переделать под сюжет
7. Превью           → python3 prev_v2.py slug "…ключевые моменты…" sheet.png → СМОТРЕТЬ глазами → править → повторять
8. Финал            → bash render.sh slug → out/slug.mp4
9. Проверка         → чек-лист ниже, раскадровка ffmpeg (fps=1/4,tile) и просмотр
```

По времени: сценарий 20–30 минут, голоса 10–15 минут, рендер-файл 1–2 часа, превью и правки 30–60 минут, финальный рендер ~10 минут.

### 7.7. Как смотреть превью

`python3 prev_v2.py market "0;S['a1_her']['t']+0.6;SC['A1']['ev']['tag']+0.6;S['c2_nar']['t']+5" sheet.png`

Здесь `S` — реплики, `SC` — сцены и их события. Получается полоска кадров 360×640. На каждом уровне проверяем 2–3 момента: реплику героини, ответ собеседника, гэг и карточку. Что мы ловили и чинили на превью:
- ценник или предмет спрятан за пузырём или за водяным знаком → переносили выше;
- голова персонажа под карточкой урока → меняли план камеры;
- рука проходит сквозь голову собеседника → меняли точку `reach`;
- летящие предметы рисовались позади героини → перенесли отрисовку после неё;
- в шрифте нет символа «♥» → нарисовали сердечко вручную;
- кадр 0 был пустым из-за «выезда» элементов → открывашку собрали полностью с нулевого кадра.

## 9. Публикация

- Публикуем **видео** (не карусель).
- **Подпись:** 1 строка с шуткой или вопросом + 4–6 хештегов. Примеры:
  - «Перевес в аэропорту на каждом уровне английского 😂 А ты бы что сказал(а)? #английский #английскийязык #урокианглийского #аэропорт»
  - «Как торговаться на английском: от А1 до C2 💸 Последний уровень — легенда #английский #английскийязык #лондон #учиманглийский»
- В первом комментарии можно задать вопрос из концовки («А как ты попросишь…?»), чтобы зрители отвечали.

## 10. Если ИИ-помощник не умеет запускать код

Движку нужна среда, где можно выполнять команды: Node, Python и ffmpeg (например, Claude с доступом к компьютеру или к облачной песочнице). Если у помощника есть только чат, он всё равно может:
1. писать сценарии в формате `examples/episode_template.py` по правилам раздела 4;
2. готовить текст диктора для ElevenLabs по правилам раздела 4.4.

Картинку, анимацию и сборку тогда делает тот, у кого есть такая среда, по разделу 7.
