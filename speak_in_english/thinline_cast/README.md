# Наши герои в стиле «тонкая линия»
- `tl_kit.js` — помощники стиля из `speak/mums/render.js` (ветка claude/eloquent-brahmagupta-nf3pp4): контур, светотень, кисти с пальцами, позы рук.
- `tl_cast.js` — героиня (тёмное каре с пробором набок, однотонное, жёлтый кардиган, блузка в горошек, серьги, розовый лак) и Том (короткая каштановая стрижка с чёлкой из прядей, зелёные глаза, синий свитер). Лицо как у Ирины: тяжёлое веко, нос-пятно, губы бантиком, рот по звукам (`VIS`: A, O, U, E, I, M, F), моргание, улыбка с прищуром, брови.
- `tl_sheet.js` — лист персонажей: `node tl_sheet.js out.png`.
Запуск: положить папку как `speak/ourcast_tl/` в checkout той ветки, `npm install` в корне.
