# Рубрика «От вежливого до грубого» — пилот «отстань» (американский английский)

Формат без сюжета: шкала-градусник 1–5, карточка уровня (кому можно сказать, фраза голосом носителя, перевод), ведущая Аня (anna.js, плоский стиль), бонус, итоговая шкала и «Сохрани».
```
node render.js still 15,44
node render.js video        # -> out/polite_scale.mp4
node render.js cover 41.5
```
