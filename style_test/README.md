# Style test (not an episode) — cinematic cartoon 2D, "The Pepsi Fighter Jet", 15 s
Silent test of a new look: characters with real faces (eyes with lids and highlights, brows, nose, mouth shapes, hair, hands), key light + coloured rim light, depth of field, bloom, vignette, grain.
Self-contained (`test.js`, does not use hirkit, not a reusable engine). Re-enactment, generic figure (no likeness). No voice, no paid generators.
