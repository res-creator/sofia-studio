# «Шуша и Кеша» — флеш-скетч в духе «Масяни» (свои герои)

Личный эксперимент владелицы. Русский язык, озвучка — fish.audio (бесплатная модель `s2.1-pro-free`, обычные голоса из библиотеки, не клоны известных людей и персонажей).

- **Шуша** — зелёные волосы с двумя «ёжиками», оранжевая худи, полосатые колготки. Вспыльчивая. Голос: fish.audio `7ac07cd587b2454090ae01f3ab9f0fd4`, немного ускорен и повышен.
- **Кеша** — сосед, фиолетовая шапка, щетина, сонные глаза. Невозмутимый. Голос: fish.audio `ea5e7471cae742bb842b04885e9eaff5`.

Серия «Йогурт»: реплики в `voice/lines.json`, сырые mp3 в `voice/`. Рот двигается по громкости голоса.
Рендер: `node shusha/render.js` → `shusha/out/yogurt.mp4` (кадры: `node shusha/render.js 6,13`).
Режиссура (поза, эмоция, камера на каждую реплику) — массив `DIR` в `render.js`.
