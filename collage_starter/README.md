# Animated Collage Documentary — стартовый набор

Это готовый набор для вертикальных TikTok-роликов в стиле **«анимированный коллаж-документалистика»**: бумажные вырезки, глубина из нескольких планов, плавная камера, озвучка, субтитры, звуки и музыка. Всё делается кодом, без ручного монтажа.

Пример внутри: ролик **«How McDonald's Really Makes Money»** — 39,6 с, 1080×1920, 30 fps, 7 сцен.

---

## Для человека — как пользоваться (3 шага)

1. Распакуй архив в пустую папку и открой её в **Claude Code**.
2. Напиши Claude одно слово: **«делай»**. Если хочешь свою тему, напиши так: **«делай: How Netflix Really Makes Money»**.
3. Если Claude попросит ключ ElevenLabs, задай его в окружении: `ELEVEN_API_KEYS=ключ`. Ключ никогда не вставляй в чат или в код.

Что понадобится: Node.js 18+, Python 3, ffmpeg и аккаунт ElevenLabs (для голоса). Остальное Claude поставит сам.

Если пользователь написал «делай» (с темой или без), выполни всё ниже сам, без промежуточных вопросов.

- **Темы нет** — выбери сам одну интересную тему в жанре «как компания/явление на самом деле зарабатывает или работает» (business explainer для англоязычного TikTok США) и сделай ролик.

Останавливайся и спрашивай только если без ответа работу не продолжить. Например: нет ключа ElevenLabs, нет ffmpeg и нет прав на установку.

### 0. Подготовка (один раз)

```sh
npm install                     # @napi-rs/canvas + запасной шрифт Nunito
pip install numpy scipy         # звук
ffmpeg -version                 # нужен ffmpeg; если нет — установи через пакетный менеджер
cd example && node episode.js still 1.9,21.6,37.0 check.png   # проверка: должен появиться лист из 3 кадров
```

- Шрифты Inter Display лежат в `fonts/` (лицензия OFL). Код подхватывает их сам.
- Перед работой прочитай скилл **`skill/vizavi-motion/SKILL.md`** и его `references/` (это правила режиссуры, камеры, глубины и проверки). Если в окружении уже установлен скилл `vizavi-motion`, используй его. Явный бриф пользователя всегда важнее значений по умолчанию из скилла: формат здесь **1080×1920, 30 fps**, а не 1920×1080/60.
- Для ориентира открой пример: `example/episode.js`, `example/STORYBOARD.md` и готовые кадры (`check.png`).

### 1. Структура проекта (не переписывай — переиспользуй)

| Файл | Что делает |
|---|---|
| `kit.js` | Стиль и объекты: палитра `C`, плавности `E`, `spring`, бумажная вырезка `cut()` (мягкая тень + белый край бумаги + контур), `contact()` (контактная тень), бумажная текстура, `tag()` (бумажный ярлык со скотчем), `applyCam()` (камера с параллаксом), `sprite()` (кэш + размытие). Объекты: `restaurant`, `slab` (участок земли в псевдо-3D), `burgerMoney` (бургер⇄стопка купюр), `coin`, `bill`, `pin`, `hq`, `continents` + `ll()` (карта мира), `fries`, `receipt`, `cloud`, `skyline`, `sparkle`, `puff`. |
| `engine.js` | Движок: `voice()` (тайминги слов из ElevenLabs), `camera(keys)` (ключи камеры + лёгкое «дыхание» + встряски на ударах), передний план с параллаксом и размытием, motion blur только на быстрых движениях камеры, размытие фона (`worldBlur`), субтитры по словам, рендер (`video` / `still` / `cues`). |
| `el.py` | ElevenLabs TTS с таймингами (ключи только из `ELEVEN_API_KEYS`). |
| `example/` | Полный пример эпизода: `script.json` (текст), `vo.py` (генерация голоса), `vo/` (готовый голос), `episode.js` (7 сцен), `mix.py` (SFX + синтезированная музыка), `build.sh`, `STORYBOARD.md`. |

**Новый ролик** = скопируй `example/` в новую папку (например `ep_netflix/`). Затем замени `script.json` и сцены в `episode.js`, а голос сгенерируй заново. `kit.js` и `engine.js` не трогай. Новые объекты добавляй в `kit.js` отдельными функциями, по возможности переиспользуемыми.

Как устроен эпизод (`episode.js`):

- `ST` — время старта каждой фразы озвучки. `w.*` — время нужных слов (`at('v4','royalties')`), к ним синхронизируй действия.
- `KEYS` — путь камеры: `{t, x, y, z, r, e}`, где `e` — плавность (`inOut`, `inOut5`, `out5`…). Сцены — это объекты `{t0, t1, draw(ctx, t)}` в одних мировых координатах. Переходы делаются через общие объекты (один предмет превращается в другой, переезжает или масштабируется).
- `background()` — дальние планы (бумага, растр, диск-акцент, город). `ep.fg` — предметы переднего плана с параллаксом. `ep.overlay` — экранная типографика (цифры, заголовок). `ep.subs` / `ep.subStyle` — субтитры. `ep.cues()` — звуки. `ep.music` — точки музыки.
- Команды: `node episode.js still 0.5,3.2,10 sheet.png` — лист кадров (дёшево). `sh build.sh` — полный рендер.

### 2. Порядок работы (экономно)

1. **Факты.** Найди официальные цифры: годовой отчёт / 10-K / сайт компании, проверь через WebSearch. Не выдумывай цифры. Выручку не называй прибылью. Если сумма не подтверждается — дай общую формулировку. Источник выведи мелким текстом в кадре с цифрами.
2. **Сценарий.** 85–110 слов, American English, разговорно, уверенно, с любопытством. Это 6–8 коротких фраз → `script.json` (одна фраза ≈ одна сцена). Цель — около 40–45 с с естественными паузами; речь не ускоряй.
   - Хук: первая фраза — вопрос или неожиданный тезис.
   - В середине — «Here's the twist».
   - Финал — короткая фраза-вывод. Без «подпишись», если это портит последний кадр.
3. **Голос.** Укажи `VOICE` в `vo.py`. Голос из примера — «Chris» (`iP95p4xoKVk53GoZ742B`, американский, разговорный), модель `eleven_multilingual_v2`. Запусти `python3 vo.py` — один запрос на фразу, не больше 2 запросов одновременно. Голосовые тесты не плоди.
4. **Тайминги.** Выпиши время слов (`V.words(id)`). Расставь `ST` с паузами 0,1–0,6 с и посчитай `T` = конец речи + 2,5–3 с на финальный кадр.
5. **Раскадровка** (из скилла). Для каждой сцены придумай 3–5 разных вариантов, выбери сильнейший и запиши в `STORYBOARD.md` таблицу: смысл, действие, текст, камера, параллакс / blur / фокус, переход, звук.
6. **Сцены.** Пиши их в `episode.js`, переиспользуя объекты из `kit.js`.
7. **Проверка кадров.** Сделай `still` по ключевым моментам и стыкам (≈15–30 кадров на лист) и посмотри картинку. Исправь только реальные проблемы.
8. **Один полный рендер.** `sh build.sh`.
9. **Проверка готового MP4** (см. чек-лист ниже).
10. **Отчёт.** Кратко опиши, что сделано. Честно различай «проверено по кадрам» и «посмотрено/прослушано».

### 3. Визуальный стиль (обязательно)

- **Палитра:** фон `#F7F5F0`, текст `#171717`, красный `#E63946`, жёлтый `#FFC857`, зелёный `#26A69A`. Допустимы спокойные оттенки бумаги, земли и серого.
- **Материал:** бумажные вырезки — заливка, тонкий тёмный контур, белый край бумаги, мягкая тень от света сверху слева. Чем выше план, тем шире и мягче тень. Поверх кадра лежит лёгкая текстура бумаги.
- **Объекты крупные и простые.** Каждая сцена строится вокруг одного главного объекта. Никаких случайных предметов «для заполнения» и мелочи.
- **Не делай:** слайды, длинные надписи, огромные постоянные субтитры, бесконечные потоки денег, одинаковые переходы, постоянную тряску, постоянный параллакс или размытый фон. Маскотов и персонажей не делай: герои — события, компании и предметы.
- **Логотипы и бренды:** делай стилизацию, не копируй логотип 1:1. Не копируй стиль The Economist и других каналов.

### 4. Камера, глубина, размытие — только по смыслу

- **Планы:** дальний (бумага и растр, размыт, параллакс ×0,25) → акцентный диск (×0,4) → город (×0,62, слегка размыт) → главный план (×1, резкий) → передний план (×1,3–1,9, сильно размыт).
- **Параллакс** используй там, где движется камера: резкое приближение, отъезд, проезд. На схемах и цифрах параллакса нет.
- **Motion blur** включается автоматически только на быстрых движениях камеры (порог в `engine.js`). На полётах объектов используй шлейф (`trail()`, «призраки» на падении).
- **Размытие фона** (`worldBlur`) — только когда главное должно оторваться от фона (например, крупные цифры).
- **Резкими всегда остаются** главные объекты, цифры и текст.
- **Камера** работает так: короткий энергичный наезд на ударе, плавный отъезд-раскрытие, медленный проезд. Во время чтения схемы камера почти стоит.
- **Переходы** каждый раз разные и связаны смыслом: превращение (бургер → купюры), объект переходит в следующую сцену (метки → рестораны), маска, масштаб, резкий перевод камеры с размытием.
- **Первые 2 секунды:** крупный объект в кадре с первого кадра, сразу движение, удар на сильную долю музыки, превращение тоже в ритм. Без вступления и логотипа.

### 5. Текст и субтитры

- Шрифт Inter Display Black / ExtraBold. Экранный текст — 1–3 слова: цифры, ярлыки (`ROYALTIES`, `RENT`), финальный заголовок. Анимация текста — выезд из-под маски, счётчик цифр, бумажная полоса.
- **Субтитры** (уже в движке): белые, тёмная обводка, мягкая тень, 62 px, до 2 строк, группы по 3–6 слов, без прыгающих букв. Жёлтым выделяй 1 ключевое слово примерно на фразу (`subStyle.highlight`). Цифры показывай цифрами (`replace`: `ninety-five percent` → `95%`).
- **Безопасные зоны TikTok:**
  - субтитры по центру x≈510, нижняя строка на y≈1350, ширина ≤ 800 px;
  - всё важное держи в зоне y 230–1240 и x 60–950;
  - справа (x > 960, y 700–1500) — кнопки, снизу (y > 1500) — описание ролика.

### 6. Звук

- Голос главный. Звуков немного, только на важные события: удар, превращение, «пуф» появления, монеты, перелистывание бумаги, свист перехода. Не одинаковый whoosh на каждом переходе.
- Музыка синтезируется в `mix.py` (своя, без вопросов лицензии): 120 BPM, первая доля = главный удар в начале (`music.b0`), пауза под поворот сюжета (`breakAt` → `back`), финальный аккорд на раскрытии (`hit`). Сдвигай эти точки под свой таймлайн. Музыка тише голоса и приглушается под речью.
- Громкость выравнивается до −14 LUFS в `build.sh`.

### 7. Чек-лист готового MP4 (обязательно)

```sh
ffprobe -v error -show_entries stream=width,height,r_frame_rate,nb_frames,codec_name,pix_fmt:format=duration video.mp4
ffmpeg -i video.mp4 -vf blackdetect=d=0.03:pix_th=0.1 -an -f null - 2>&1 | grep -c black_start   # должно быть 0
ffmpeg -i video.mp4 -af ebur128 -f null - 2>&1 | grep -A8 Summary                                   # I около -14..-16 LUFS, LRA небольшой
```

- 1080×1920, 30 fps, H.264 yuv420p + AAC, длительность ≈ T, корректный конец.
- **Озвучка:** распознай звук готового файла через ElevenLabs Speech-to-Text (`POST https://api.elevenlabs.io/v1/speech-to-text`, `model_id=scribe_v1`, ключ в заголовке `xi-api-key`) и сравни со `script.json`. Пропусков быть не должно, числа произнесены верно, последнее слово не обрезано.
- **Синхронизация:** найди атаки звука на ключевых ударах в декодированном аудио и сравни с кадрами.
- **Кадры:** сделай тайлы кадров из готового MP4 (`ffmpeg -vf "select=...,scale=216:-1,tile=8x3"`) на старте, на всех стыках сцен, на быстрых фазах и в конце. Проверь, что ничего не обрезано, текст не перекрыт, субтитры читаются, нет пустых кадров с мелкими объектами.
- Не заявляй, что смотрел или слушал ролик, если проверял только по кадрам и цифрам.

### 8. Экономия

- Не переписывай `kit.js` и `engine.js`, не делай несколько версий и стилевых экспериментов.
- Сначала листы кадров (`still`), потом один полный рендер (~3 минуты на 40 с). Повторный рендер — только при реальной ошибке.
- Секреты (ключи API) — только в переменных окружения, никогда в коде, git или чате.
