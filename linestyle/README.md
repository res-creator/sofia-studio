# Проба стиля «тонкая линия» (как wittiger.art), своя героиня
Тонкий ровный контур, плоские цвета без теней, волосы двумя оттенками, карикатурные детали (тени на веках, ресницы, мешки, морщинки, губы, серьги, бусы), бумажное зерно, полупрозрачное облачко с тонкими буквами в разрядку, подпись сверху.
Героиня — психолог Ирина Павловна. Скетч «Сеанс», 11 с. Музыка и звуки из `asya/audio`.
Рендер: `node linestyle/render.js` → `linestyle/out/psiholog.mp4`. Подпись сверху — `@SHUSHA.ART` (функция `watermark`).
