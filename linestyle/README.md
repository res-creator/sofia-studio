# Проба стиля «тонкая линия» (как wittiger.art), своя героиня
Тонкий ровный контур, плоские цвета, бумажное зерно, полупрозрачное облачко с тонкими буквами в разрядку, подпись сверху.
Героиня — психолог Ирина Павловна, проработана подробно: пышная фигура, платье с запахом в горошек, шаль, бусы, серьги, руки с пятью пальцами, ногтями и кольцом, объёмная причёска в два цвета с прядями, тени на веках, ресницы, морщинки, родинка, губы с зубами и языком (рот двигается по голосу).
Озвучка — fish.audio, бесплатная модель `s2.1-pro-free`, голос `aa615eaff73f417e91cfbb4ea0e42df8` («женский голос средних лет»); реплики в `voice/lines.json`.
Рендер: `node linestyle/render.js` → `linestyle/out/psiholog.mp4`. Подпись сверху — `@SHUSHA.ART` (функция `watermark`).
