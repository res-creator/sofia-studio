# Speak in English — «4 типа мам» в новом стиле (проба)
Тот же формат, что в старом ролике (номера 01–04, двуязычные облачка EN/RU, караоке-субтитры, финальный призыв), но героиня в новом стиле `linestyle/`: тонкий контур, проработанное лицо, рот по звукам английской речи, плавные позы рук, светотень.
- Мама: 4 образа (советница, генерал с половником, логист в розовых очках, шпион в тёмных очках с телефоном).
- Голоса: fish.audio бесплатная модель `s2.1-pro-free`. Мама (EN) `b6d5ed38678e4c48b292388207c6ef89`, диктор (RU) `7ac07cd587b2454090ae01f3ab9f0fd4`. Текст в `voice/script.json`.
- Рендер: `node speak/mums/render.js` → `speak/mums/out/mums_new_style.mp4` (~45 с).
