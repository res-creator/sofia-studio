# Montage test (15 s, picture only)
Tests whether the figmakit engine can reproduce the editing language of the two Nvidia reference videos
(slow push-ins, pull-back reveal, whip / flash / iris transitions, punch-in + shake, emotion marks, yellow tags,
word-pop title with underline, speed-lines burst, black typewriter card).
Art = existing figmakit assets only. Run: `node montage_test.js video montage_test_15s.mp4` (needs `npm install` in repo root).
