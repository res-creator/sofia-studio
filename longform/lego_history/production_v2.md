**Plates and props:** P1–P14 are plates (§4); K1–K6 are prop sheets (§5); R = re-used from `figmakit/assets/`.

**Camera:** push = slow push-in · pull = pull-back reveal · pan · punch = quick punch-in · drift = always on.

**Transitions:** whip · flash · black · cut.

**The recurring device: the toy town (TT).** It is built in code on plate P5 from the K1, K2 and K6 sprites, with one state per chapter:

| State | What the town looks like |
|---|---|
| TT-clean | a few piece types, repeated |
| TT-grow | more of the same pieces |
| TT-sprawl | hundreds of one-off pieces, each with its own bin and mold; everything still clicks together, but the shelves behind overflow |
| TT-dark | lights out, empty shelves |
| TT-rebuilt | few piece types again, used everywhere |

**Motif rule (v2.1).** New pieces are never shown failing to connect. They always click on. The problem is shown as **reuse and cost**: each one-off piece gets its own bin, its own mold and its own line in a ledger, and is used once.
