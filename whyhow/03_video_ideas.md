# Step 3 — 20 video ideas

Mix of the three pillars: **P** = extreme place, **E** = how it works (engineering), **S** = survival / what if.
"Hook" = the strangest true fact we open with (must be checked again before scripting — these are leads, not final facts).
Order = suggested release order (strong, searchable topics first; Russia/Arctic topics close to the reference channels' hits).

Before scripting any idea: re-check every hook fact (several of the hooks above are popular claims that need a primary source),
and search YouTube for the same question — if a big channel did it in the last 12 months, take a sharper angle.
Ideas 2, 3, 4, 17 are the closest to the reference channels' biggest hits (taiga, cold, Siberia).
