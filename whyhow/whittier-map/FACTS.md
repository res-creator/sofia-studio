Not used / not confirmed:
- Exact closing hours: not given by these sources. The Alaska DOT&PF schedule page (https://dot.alaska.gov/creg/whittiertunnel/schedule.shtml) returned HTTP 503 when checked (25 Nov 2026), so the film says only "closes at night". Check the current summer/winter schedule before publishing if hours are added.
- NPR, "Welcome To Whittier, Alaska, A Community Under One Roof" (2015): HTTP 503 on three attempts; not used.
