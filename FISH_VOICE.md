# Озвучка своим голосом через Fish Audio и Claude Code

Голос клонируется один раз (сохраняем образец), дальше любой фильм озвучивается этим голосом одной командой.
Модель: `s2.1-pro-free` (бесплатная, качество как у s2.1-pro). По правилам Fish Audio бесплатная модель — для некоммерческого использования.

## 1. Подключить Fish Audio (один раз)
1. Зарегистрироваться на https://fish.audio.
2. Developers → API Keys → Create → скопировать ключ.
3. Сохранить ключ в файл (сам, руками — НЕ вставлять ключ в чат с Claude):
   - открыть приложение «TextEdit», меню Формат → «Сделать обычным текстом»;
   - вставить ключ одной строкой, без пробелов;
   - Файл → Сохранить: имя `fish_audio_key.txt`, папка — **домашняя** (с иконкой домика, где «Загрузки», «Документы»).
   Скрипт сам найдёт ключ в `~/fish_audio_key.txt`. Файл не класть в папку проекта и не отправлять никому.
   (Работает и в приложении Claude Code на компьютере, и в терминале. В терминале можно вместо файла задать переменную FISH_API_KEY.)
4. Зависимости Claude Code поставит сам: `pip install ormsgpack numpy soundfile scipy` и ffmpeg.

## 2. Клонировать голос (один раз)
1. Записать образец: 1–3 минуты, чистый голос без музыки, MP3 192 kbps или WAV,
   на том же языке, что озвучка (русские фильмы — русский образец). С живыми эмоциями: тепло, удивление, серьёзно, шёпот, лёгкий смех.
2. Сохранить в папку, например `~/voices/my_voice/`:
   - `ref.mp3` — образец;
   - `ref_text.txt` — точный текст того, что звучит в образце (без тегов).
3. Всё: это и есть «клон». Fish Audio берёт голос из образца при каждой генерации, сохранять модель на сайте не нужно.

## 3. Озвучить фильм (каждый раз)
Написать своему Claude Code в папке фильма:
> Прочитай FISH_VOICE.md. Озвучь этот фильм через Fish Audio моим голосом: образец ~/voices/my_voice/ref.mp3, текст образца ~/voices/my_voice/ref_text.txt,
> текст фильма в SCRIPT.csv (колонка <название колонки с текстом>). Сначала 5 абзацев на пробу, потом весь фильм. Ключ лежит в ~/fish_audio_key.txt, не показывай его.

Claude Code запустит:
```
python3 fish_voice.py --ref ~/voices/my_voice/ref.mp3 --ref-text ~/voices/my_voice/ref_text.txt --csv SCRIPT.csv --text-col <колонка> --out voice_raw --ids F001 F002 F003 F004 F005
python3 fish_voice.py --ref ~/voices/my_voice/ref.mp3 --ref-text ~/voices/my_voice/ref_text.txt --csv SCRIPT.csv --text-col <колонка> --out voice_raw
python3 master_voice.py      # voice_raw -> voice, студийная обработка (обязательно)
python3 onset_check.py       # глухие начала -> перегенерировать их: fish_voice.py ... --ids F012 F040
python3 place_voice.py       # расставить по таймингу, свести с музыкой, собрать видео
```

## 4. Правила качества
- Эмоция: первый тег из колонки `delivery_notes` (например `[warm]`, `[amused]`, `[serious]`) уходит в Fish как подсказка, вслух не читается.
- Каждая фраза должна быть короче `max_duration_s`. Если длиннее — сократить фразу (не числа и не имена), поправить субтитры и перегенерировать только её (`--ids`).
- Числа писать словами. Трудные названия — по звучанию (только в тексте для озвучки, не в субтитрах).
- Запросы по одному (скрипт так и делает и сам повторяет при перегрузке).
- Голос в образце должен быть вашим или с согласия владельца. Если образец сделан в ElevenLabs — проверьте их условия на такое использование.

## 5. Проверка перед публикацией
Громкость −14 LUFS, пик не выше −1 dBTP, длительность = длительности картинки, послушать начало, главы и конец.
