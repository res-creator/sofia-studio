# Озвучка через Fish Audio (клон своего голоса) — инструкция для Claude Code

Подходит для русских и английских фильмов. Голос клонируется по образцу; модель на аккаунте сохранять не нужно —
образец отправляется вместе с каждой фразой (скрипт `dubtools/fish_voice.py`).

## 1. Один раз: аккаунт и ключ
- fish.audio → Developers → API keys → создать ключ.
- Пополнить API-баланс (Developers → Billing). Цена s2.1-pro: $15 за 1 млн байт текста.
  50-минутный фильм ≈ 70 тыс. байт по-английски (≈ $1) и ≈ 130 тыс. байт по-русски (кириллица 2 байта на букву, ≈ $2).
- Ключ хранить только в переменной окружения: `export FISH_API_KEY=...` — никогда в файлах и в git.

## 2. Права (важно для монетизации)
- Бесплатная модель `s2.1-pro-free`: по правилам Fish Audio бесплатное использование — только некоммерческое. Для канала с монетизацией — платный API (`s2.1-pro`).
  Точный статус pay-as-you-go API для коммерции лучше подтвердить письмом в support@fish.audio.
- Голос в образце должен принадлежать вам (или есть согласие человека). Если образец сгенерирован в ElevenLabs — проверьте их условия:
  разрешено ли использовать их аудио как образец для клона в другом сервисе.

## 3. Образец голоса
- 1–3 минуты, чистый голос без музыки, MP3 192 kbps или WAV, на ТОМ ЖЕ языке, что озвучка (русский фильм — русский образец).
- Живые эмоции (тепло, удивление, серьёзно, шёпот, лёгкий смех): клон повторит манеру.
- Рядом файл `ref_text.txt` — точный текст того, что звучит в образце (без тегов). От этого сильно зависит качество.

## 4. Озвучка фильма
В папке фильма (где SCRIPT.csv с колонками `id`, текст, `max_duration_s`, `delivery_notes`):
```
pip install ormsgpack numpy soundfile scipy
python3 fish_voice.py --ref ref.mp3 --ref-text ref_text.txt --csv SCRIPT_EN.csv --out voice_raw --model s2.1-pro
python3 master_voice.py            # voice_raw -> voice (обязательно)
python3 onset_check.py             # глухие начала -> перегенерировать: fish_voice.py ... --ids F012 F040
python3 place_voice.py             # расставить по таймингу, свести с музыкой, собрать видео
```
- Для русского текста колонку указать: `--text-col russian_text` (или как она называется).
- Эмоция: первый тег из `delivery_notes` (например `[warm]`) уходит в Fish как подсказка; остальное не читается.
- Если строка длиннее `max_duration_s` — сократить фразу (не числа и не имена), поправить субтитры, перегенерировать только её (`--ids`).
- Числа писать словами. Сложные названия — по звучанию (только в тексте для озвучки, не в субтитрах).
- Не больше 2–3 запросов одновременно; скрипт идёт по одному и сам повторяет при 429.

## 5. Проверка
- Сначала озвучить 5–8 абзацев и послушать. Потом весь фильм.
- После сборки: громкость −14 LUFS, пик не выше −1 dBTP, длительность = длительности картинки.
