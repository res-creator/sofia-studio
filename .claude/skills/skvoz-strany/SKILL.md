# «Сквозь страны» — выпуск от темы до загрузки

Основа — процесс канала-партнёра (`ru_geo/docs/PROCESS_GUIDE.md`, владелица передала 09.11.2026) и наши правила `ru_geo/docs/RULES.md`.
**Прочитай оба файла в начале каждого выпуска.** Если владелица говорит иначе — её слово главнее; новое правило сразу допиши в `RULES.md` и сюда.
Берём процесс, тон и качество. **Не берём** чужое оформление и слова: имя «Пристегнитесь!», «пристегнитесь/пристёгивайся», их плашки, шрифты, заголовки;
не копируем фразы и приёмы Птушкина (катакана → русское название, «Есть страны, куда едут один раз…»). Всё — своими словами и в своём дизайне.

## Общение с владелицей
- Пишет по-русски, отвечать просто и коротко, без кода и логов (читает с телефона). Честно: если плохо — так и сказать; называть реальный срок.
- В конце каждого шага — прямые ссылки GitHub: PR, папка ветки, файлы (MP4 через `media.githubusercontent.com/media/...` для LFS, обложка, SRT, upload kit).
- Перед тратой кредитов ElevenLabs — только после одобрения текста; голоса показывать ссылками, без генерации проб.
- Решения владелицы (темы, обложка, музыка) записывать в `ru_geo/<страна>/PLAN.md`; журнал — `ru_geo/STATUS.md`.

## Порядок работы (контрольные точки владелицы помечены ✋)
1. **Тема.** Сравнение/парадокс и связь с русским зрителем работают лучше всего («Почему X опаснее Y?», «страна, где …»). Можно разобрать
   конкурентов через vidIQ (`vidiq_channel_videos`, `vidiq_video_transcript`), но не копировать.
2. **Исследование** (помощник-исследователь): факты, цифры, истории людей, свежие данные, источники (ООН, ВБ, ЮНЕСКО, официальная статистика).
3. **Сценарий** (помощник-сценарист) → `ru_geo/<страна>/SCRIPT.md`: холодный старт с шоком/вопросом в первые 5 с, весь фильм — один крючок,
   отложенные ответы, главы по 3–6 мин, контраст (красота + трудная сторона, с уважением), 1–2 истории людей, ~30 с философской паузы при уместности,
   мало шуток, но точных, одна остроумная просьба подписаться на 20–30 % фильма, конец отвечает на загадку из начала + вопрос в комментарии.
   Числа словами для озвучки. Длина 20–34 мин (≈ 140 слов/мин).
4. **Критики** — специальные агенты проекта (`.claude/agents/`): `skvoz-critic-viewer`, `skvoz-critic-judge`, `skvoz-factchecker`. Два критика: «Зритель с телефона» (удержание, крючки, первые 2 мин, юмор, оригинальность) и «Честный судья» (факты, баланс,
   уважение). Плюс **фактчекер**, который не видел исследования. Круги правок до 10/10 по каждому пункту; таблицу оценок сохранять. ✋ текст владелице.
5. **Озвучка — один раз** (`vo_el.py`/`vo_full/make.py` как образец): ElevenLabs v3, голос Todd `g14YnDYCsy3k7XLlcKlO`, stability 0.0, similarity 0.8,
   теги [curious] [warmly] [chuckles] [laughs softly] [excited] — редко. Перед стартом проверить аккаунт:
   `curl -sS https://api.elevenlabs.io/v1/user/subscription -H "xi-api-key: proxy"` — тариф и остаток; `mp3_44100_192` только на Creator+,
   на PAYG — `mp3_44100_128`. По одному запросу, пауза 3 с; ошибочный ответ не сохранять поверх готового файла (писать во временный).
   Проверка: faster_whisper medium локально (decode через ffmpeg в float32 16 кГц — `av` в этой среде ломается). Сбой (обрыв, лишнее слово) —
   сначала вырезать ffmpeg-ом, переозвучивать только фразу, если иначе нельзя; если слово «проглатывается» дважды — перефразировать.
6. **Подбор кадров** — помощники по частям фильма с брифом как `ru_geo/japan/shots/BRIEF.md` и `review/FIX_BRIEF.md`:
   «говорим — показываем» для каждой фразы; только настоящая страна; без ИИ/3D/аниме, водяных знаков, чужих титров; 4K приоритет.
   Видео: Pixabay API (ключ только из env `PIXABAY_API_KEY`, не печатать), Mixkit (только 720p), Coverr. Pexels недоступен.
   Фото, где видео нет: Wikimedia Commons (`lib/commons_find.py`, `lib/commons_html.py`, превью/оригинал через thumb.wikimedia.org),
   только CC0/PD/CC BY/CC BY-SA, авторы в `shots/commons_credits_*.json`; фото не больше половины кадров абзаца, не больше 2 подряд.
   Ловушки прошлых выпусков: «японские» стоки из Вьетнама/Китая/Кореи, западные интерьеры вместо японских, логотипы брендов, ИИ-клипы с шириной 3872.
   После подбора — общий скрипт повторов (один клип не чаще раза в 3 мин и с другим `ss`).
7. **Монтаж в коде** — шаблон `ru_geo/japan/full2/` (скопировать в `ru_geo/<страна>/full/` и поправить):
   `plan.py` (таймлайн голоса, кадры, вступление-трейлер `INTRO2`, музыкальные паузы `INTERLUDE`, подписи/окна `EXTRAS`, пометки `NOTES`,
   карточки `NUMCARDS`, музыка по главам `MUSIC` с громкостью и сдвигом), `fetch.py` (качает 4K и сразу режет нужный кусок), `build.py` (рендер).
   Приёмы (наш дизайн): трейлер ~1 план/с; дальше 2–4 с; каждые 1–3 мин 10–30 с только музыки на лучших пролётах; название страны за
   движущимся объектом (маска по цвету неба / rembg), кадр из ч/б в цвет, печать-символ страны; подписи мест слева внизу — матовое стекло,
   бирюзовая черта, Inter капсом; «окно» со скруглёнными углами в 3–5 ключевых местах; рукописные пометки (Caveat) ≤ 5 на фильм; карточки с цифрой
   редко; заставки глав (Cormorant Garamond с разрядкой, затемнение под текстом); цвет: глубокие тени с бирюзой, тёплый свет; полосы ≈ 2,2:1, зерно, виньетка.
   Никакого текста короче 1,5–2 с, только короткое тире «-» в надписях. В конце 10–15 с спокойного хвоста под конечную заставку.
8. ✋ **Тест 2 минуты** нового стиля: `python3 build.py --until 140 --jobs 4` → лист кадров → 720p в `video/` → ссылка владелице.
9. **Черновик 1080p** всего фильма → помощники-проверяющие по зонам (кадры ×2, звук и техника, сценарий и зритель) с брифом как
   `ru_geo/japan/review/BRIEF.md` → правки → ✋ 720p-черновик владелице.
10. **Финал** (только если владелица хочет 4K): `python3 build.py --4k --jobs 4` — HEVC 10 бит ~20 Мбит/с, hvc1, AAC 320k, −14 LUFS.
11. **Упаковка** (`make_kit.py`): `upload_kit.txt` (название-крючок, описание с главами, строка «Озвучка сделана с помощью ИИ, факты проверены
    по источникам», музыка и авторы по лицензиям, хэштеги строчными, теги, закреплённый комментарий-вопрос «…пиши цифру!», пометка «синтетический
    контент»), `CREDITS.md`, субтитры `.srt` отдельно. ✋ **Обложка**: 2–3 варианта листом (`cover/make_cover.py`: огромное название, герой перед буквами
    через rembg, узнаваемый фон, 2–4 слова-крючок в плашке, проверка в 160–320 px). Обложка канала F-стиля (яркий кадр + крупное слово + плашка) понравилась.

## Музыка
По главам, тёплая, никогда не мрачная, местный колорит + тревел. Источники: Kevin MacLeod (incompetech.com, CC BY 4.0 — указать автора), Wikimedia Commons
(CC BY / CC0), YouTube Audio Library. Pixabay Music закрыт Cloudflare — не обходить. Громкость выравнивать по замеру LUFS (≈ −30 LUFS до приглушения),
пустые секунды в начале трека пропускать (`MUSIC = {глава: (файл, громкость, сдвиг)}`), под голосом sidechain, итог −14 LUFS.
Перед выбором — сборка-сэмплер из 6–8 отрывков по 18 с, владелица выбирает номера.

## Среда (облачный контейнер) — уроки
- Машина засыпает, когда нет активного хода: долгий рендер вести, не завершая ход (ожидание циклом по ≤ 10 мин), рендер кусками (`nparts`),
  готовые куски пропускаются при перезапуске.
- Диск ограничен (~6–8 ГБ свободно): хранить только вырезанные куски клипов (`data/pixabay/seg/`), удалять старые кэши и промежуточные файлы;
  ограничивать битрейт (зерно раздувает файлы). Память 15 ГБ: rembg и другие тяжёлые вещи не запускать параллельно с 4K-рендером.
- Git: файлы > 100 МБ — через Git LFS (`git lfs track <файл>`), ссылки `media.githubusercontent.com/media/...`; MP4 > 400 МБ не отправлять в чат.
- Коммитить и пушить в рабочую ветку после каждого шага (хук проверяет незакоммиченные файлы).

## Чек-лист перед отправкой

- [ ] факты проверены, числа совпадают в голосе и на экране; в субтитрах нет тегов озвучки
- [ ] музыка без провалов и обрывов, громкость ровная; итог −14 LUFS, пик ≤ −1 dBTP
- [ ] заставки и надписи читаются и не вылезают за края; текст ≤ правил по количеству
- [ ] обложка читается в 160 px; описание < 5000 знаков; авторы по лицензиям
- [ ] ссылки владелице: PR, папка, видео, обложка, SRT, upload kit
