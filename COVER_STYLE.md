# Обложки «туристический постер» — инструкция для Claude / ChatGPT

Как писать запрос на обложку для любого фильма о стране. Отдайте этот файл своему Claude и попросите:
«Прочитай COVER_STYLE.md и напиши 4 запроса для ChatGPT на обложку фильма <страна>. Вот текст фильма: <SCRIPT>».

## Стиль
1. Яркое, сочное, «постерное» фото одного главного места страны, закат или рассвет, насыщенные цвета.
2. Огромное название страны белыми буквами (жирный рубленый шрифт) через всю обложку.
3. Эффект глубины — один из приёмов:
   - здание / человек / предмет стоит ПЕРЕД буквами и закрывает их низ (не больше трети букв!);
   - буквы стоят на воде и отражаются в ней;
   - буквы за склоном / ветками, передний план перекрывает их край.
4. Над названием — короткий вопрос-интрига рукописным белым шрифтом (главная загадка фильма).
5. Значок «4K» в тонкой белой рамке в левом нижнем углу.
6. 16:9, 1280×720.

## Правила (обязательно)
- **Только места и вещи, которые есть в фильме.** Сначала найди их в тексте фильма (с таймкодом), потом пиши запрос. Нет в фильме — нельзя на обложку.
- **Вопрос-интрига — из фильма** (цифра или загадка, которую фильм объясняет).
- Название страны должно читаться целиком даже маленьким: объект перед буквами закрывает только их низ.
- Никаких жёлтых плашек, толстых обводок, иконок-кружочков — это выглядит как дешёвый ИИ.
- Никакой эксплуатации: детей в нищете, крови, полураздетых людей.
- Каждый запрос — разное место и разный приём (для теста нужны разные обложки).
- Текст на обложке на языке канала (английский канал — английский текст, русский — русский).

## Шаблон запроса (на английском, для ChatGPT)
```
Create a vivid, rich, saturated travel-poster YouTube thumbnail, 16:9, 1280x720, photorealistic, crisp detail.
Scene: <ГЛАВНОЕ МЕСТО ИЗ ФИЛЬМА>, at golden sunrise / sunset, <2–3 детали: люди, лодки, цветы, огни>.
Text: a huge bold white word "<СТРАНА>" <ПРИЁМ: placed behind the <объект>, so the <объект> overlaps only the bottom third of the letters / standing on the water with its mirror reflection below>. All letters must stay clearly readable. Above it, small elegant white handwritten script: "<ВОПРОС-ИНТРИГА>". Small "4K" badge in a thin white rounded outline in the bottom-left corner.
Spell every word exactly as written. No other text, no logos.
```

## Правка, если объект закрыл буквы
```
Keep everything the same, but move the <объект> down and make it smaller, so it covers only the bottom third of the letters. All letters "<СТРАНА>" must be clearly readable. Keep the script text and the 4K badge exactly as they are.
```

## После ChatGPT
- проверить буквы (каждую);
- лица и руки без искажений;
- перевести в JPG 1280×720 (до 2 МБ);
- в YouTube Studio → «Тест и сравнение»: 3 разные обложки.

- VIETNAM: Золотой мост, каменные руки держат буквы.
- INDIA: Варанаси, буквы отражаются в Ганге, «as it is».
